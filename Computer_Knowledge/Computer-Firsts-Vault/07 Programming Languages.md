# Programming Languages - who made what

Back to [[00 Index]] · [[Priority - High]] · [[Priority - Medium]] · [[Priority - Low]]

Language generations: 1GL machine, 2GL assembly, 3GL high-level, 4GL query/report (SQL), 5GL AI/logic (Prolog).

## Questions (important first)

| Priority | Question | Answer | Note |
|---|---|---|---|
| 🔴 High | First widely used high-level language? | **FORTRAN (1957)** | John Backus, IBM; FORmula TRANslation, scientific work. Plankalkul (Zuse) was designed earlier but not used |
| 🔴 High | Machine language belongs to which language generation? | **1GL (binary 0/1)** | Assembly = 2GL; high-level = 3GL; SQL = 4GL; Prolog/AI = 5GL |
| 🔴 High | Business-oriented language of 1959? | **COBOL (Common Business Oriented Language)** | Grace Hopper's FLOW-MATIC was a major influence |
| 🔴 High | Who developed C? | **Dennis Ritchie (Bell Labs, 1972)** | Unix was rewritten in C in 1973; B (Ken Thompson) came before |
| 🔴 High | Who developed C++? | **Bjarne Stroustrup** | Began 1979 as 'C with Classes'; named C++ in 1983; first release 1985 |
| 🔴 High | Who developed Java? | **James Gosling (Sun Microsystems, 1995)** | Began as Oak; 'write once, run anywhere' |
| 🔴 High | BASIC: full form and creators? | **Beginner's All-purpose Symbolic Instruction Code; John Kemeny and Thomas Kurtz (Dartmouth, 1964)** |  |
| 🔴 High | Who created the first compiler? | **Grace Hopper (A-0 System, 1952)** | Called 'Queen of Code' and 'Amazing Grace' |
| 🔴 High | Creator of Python? | **Guido van Rossum (1991)** | Named after Monty Python, not the snake |
| 🟡 Medium | First object-oriented language? | **Simula (1967)** | Ole-Johan Dahl and Kristen Nygaard; Smalltalk (Alan Kay, 1972) was the first pure OOP language |
| 🟡 Medium | Pascal: creator and name origin? | **Niklaus Wirth (1970); named after Blaise Pascal** |  |
| 🟡 Medium | LISP creator? | **John McCarthy (1958)** | Second-oldest high-level language still in use; used in AI |
| 🟡 Medium | JavaScript creator? | **Brendan Eich (Netscape, 1995)** | Written in about 10 days; first called Mocha, then LiveScript |
| 🟡 Medium | HTML creator? | **Tim Berners-Lee (1991)** | HTML5 became a W3C Recommendation in 2014 |
| 🟡 Medium | Relational model and SQL? | **Relational model: E. F. Codd (IBM, 1970); SQL: Donald Chamberlin and Raymond Boyce (IBM, 1974)** |  |
| 🟡 Medium | Language named after Ada Lovelace? | **Ada (1980)** | US Department of Defense; Jean Ichbiah's team |
| 🟢 Low | ALGOL? | **Algorithmic Language (1958/60); first block-structured language; introduced BNF notation** |  |
| 🟢 Low | Perl? | **Larry Wall (1987)** |  |
| 🟢 Low | PHP? | **Rasmus Lerdorf (1994-95)** |  |
| 🟢 Low | Ruby? | **Yukihiro Matsumoto (1995)** |  |
| 🟢 Low | C# creator? | **Anders Hejlsberg (Microsoft, announced 2000)** |  |
| 🟢 Low | Go language? | **Google (2009); Robert Griesemer, Rob Pike, Ken Thompson** |  |
| 🟢 Low | Swift? | **Apple (2014)** |  |
| 🟢 Low | Logo and turtle graphics? | **Seymour Papert (1967)** |  |
| 🟢 Low | Prolog? | **Alain Colmerauer (1972)** | Logic programming; a fifth-generation language |
| 🟢 Low | Plankalkul? | **Konrad Zuse, designed 1942-45; first designed high-level language** | Not implemented until 1975 |
| 🟢 Low | Autocode? | **Alick Glennie (1952); first compiled language (Manchester Mark 1)** |  |
| 🟢 Low | CSS first specification? | **1996 (proposed 1994 by Hakon Wium Lie)** |  |
