# Viruses, Worms and Cyber Security

Back to [[00 Index]] · [[Priority - High]] · [[Priority - Medium]] · [[Priority - Low]]

Virus firsts and India's cyber law. Creeper, Elk Cloner, Brain and the Morris worm are the usual four.

## Questions (important first)

| Priority | Question | Answer | Note |
|---|---|---|---|
| 🔴 High | First computer virus (experimental)? | **Creeper (1971)** | Bob Thomas, BBN, on ARPANET; Reaper was the first antivirus-like program |
| 🔴 High | First virus for IBM PCs? | **Brain (1986)** | Written by Basit and Amjad Farooq Alvi, Lahore, Pakistan |
| 🔴 High | First virus found in the wild on personal computers (Apple II)? | **Elk Cloner (1982)** | Rich Skrenta, age 15 |
| 🔴 High | Who coined the term 'computer virus'? | **Fred Cohen (1983-84)** | His adviser Leonard Adleman suggested the term |
| 🔴 High | First Internet worm? | **Morris Worm (1988)** | Robert Tappan Morris; first person convicted under the US Computer Fraud and Abuse Act |
| 🔴 High | India's first cyber law? | **Information Technology Act, 2000** | Passed June 2000; in force 17 October 2000 |
| 🟡 Medium | ILOVEYOU worm? | **2000 - from the Philippines** |  |
| 🟡 Medium | Melissa virus? | **1999 - macro virus spread by email** |  |
| 🟡 Medium | Stuxnet? | **2010 - first known digital weapon; targeted Iran's nuclear centrifuges** | Widely attributed to the US and Israel |
| 🟡 Medium | First ransomware? | **AIDS Trojan / PC Cyborg (1989)** | Joseph Popp |
| 🟡 Medium | WannaCry? | **2017 ransomware worm** |  |
| 🟡 Medium | CERT-In? | **Indian Computer Emergency Response Team (2004)** | Under the IT ministry |
| 🟡 Medium | First commercial antivirus? | **1987 - Bernd Fix wrote a Vienna virus remover; McAfee Associates was founded 1987** |  |
| 🟢 Low | Term 'phishing'? | **1996 (AOL)** |  |
| 🟢 Low | Code Red? | **2001 worm** |  |
| 🟢 Low | India's first dedicated data protection law? | **Digital Personal Data Protection Act, 2023** |  |
