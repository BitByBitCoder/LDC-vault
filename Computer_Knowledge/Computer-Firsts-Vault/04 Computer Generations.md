# Computer Generations

Back to [[00 Index]] · [[Priority - High]] · [[Priority - Medium]] · [[Priority - Low]]

| Gen | Period | Technology | Typical examples | Software |
|---|---|---|---|---|
| 1st | 1940-1956 | Vacuum tubes | ENIAC, EDVAC, UNIVAC I | Machine language |
| 2nd | 1956-1963 | Transistors | IBM 1401, IBM 7090 | Assembly, early FORTRAN/COBOL |
| 3rd | 1964-1971 | Integrated circuits | IBM 360, PDP-8 | Operating systems, time-sharing |
| 4th | 1971-present | Microprocessors / VLSI | Altair 8800, Apple II, IBM PC | GUI, networking |
| 5th | Present and beyond | AI, ULSI, parallel/quantum | Expert systems, robotics | Natural language, AI |

Year ranges differ slightly between textbooks; match the **technology** to the generation.

## Questions (important first)

| Priority | Question | Answer | Note |
|---|---|---|---|
| 🔴 High | Technology of first-generation computers? | **Vacuum tubes (1940-1956)** | Machine language; huge, hot, unreliable. Examples: ENIAC, EDVAC, UNIVAC I |
| 🔴 High | Technology of second-generation computers? | **Transistors (1956-1963)** | Assembly and early high-level languages. Examples: IBM 1401, IBM 7090 |
| 🔴 High | Technology of third-generation computers? | **Integrated circuits (1964-1971)** | Operating systems and time-sharing. Examples: IBM System/360, PDP-8 |
| 🔴 High | Technology of fourth-generation computers? | **Microprocessors / VLSI (1971-present)** | Personal computers and GUI. Examples: Apple II, IBM PC |
| 🔴 High | Technology of fifth-generation computers? | **Artificial intelligence, ULSI, parallel processing (present and beyond)** | Natural language, robotics, expert systems; Japan started its Fifth Generation project in 1982 |
| 🟡 Medium | Which generation introduced the operating system and multiprogramming? | **Third** |  |
| 🟡 Medium | Which generation introduced the stored-program concept? | **First (EDSAC/EDVAC era)** |  |
| 🟡 Medium | Main memory in each generation? | **1st: magnetic drum / delay line; 2nd: magnetic core; 3rd: semiconductor memory; 4th: semiconductor RAM (VLSI)** |  |
| 🟡 Medium | Second-generation computers used which languages? | **Assembly language plus early high-level languages (FORTRAN, COBOL)** |  |
| 🟡 Medium | Example machines of the 2nd generation? | **IBM 1401, IBM 7090/7094, CDC 1604** |  |
| 🟡 Medium | Example machines of the 3rd generation? | **IBM 360/370, PDP-8, PDP-11** |  |
| 🟡 Medium | Example machines of the 4th generation? | **Altair 8800, Apple II, IBM PC, Cray-1** |  |
| 🟡 Medium | Which generation brought the GUI and mouse to the mass market? | **Fourth** |  |
| 🟢 Low | Drawbacks of first-generation computers? | **Large, hot, power-hungry, short-lived tubes, machine language only** |  |
| 🟢 Low | Why do generation dates differ between books? | **Authors draw the boundaries differently (e.g. 1946-59 for the first generation in some texts)** | Match the technology rather than exact years |
