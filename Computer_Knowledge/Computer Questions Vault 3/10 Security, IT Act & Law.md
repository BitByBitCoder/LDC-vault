# Part 1: Learn the topic

## 1. Malware

| Type | Behaviour |
|---|---|
| Virus | attaches to files, spreads when opened |
| Worm | spreads by itself over networks |
| Trojan horse | looks useful, hides harm |
| **Stealth virus** | **hides** from antivirus |
| **Polymorphic virus** | **changes its own code** each time |
| Macro virus | in documents |
| Boot sector virus | infects boot area |
| Ransomware | locks files, demands money |
| Spyware | secretly collects information |
| Adware | shows unwanted ads |

First virus on ARPANET: **Creeper**.

## 2. Cyber attacks

| Attack | Meaning |
|---|---|
| **Phishing** | fake email or message to steal data, appears trustworthy |
| **Pharming** | redirects to a fake website |
| **Phreaking** | hacking telephone systems |
| Spamming | unsolicited bulk email |
| Salami attack | many tiny thefts |
| Hacking | unauthorised access |
| DoS | flood a service to make it unavailable |
| Spoofing | pretending to be someone else |

## 3. Protection

| Measure | Does |
|---|---|
| Antivirus | detects and removes malware |
| Firewall | filters network traffic |
| Encryption | scrambles data |
| Authentication | password, OTP, 2FA |
| **Biometrics** | fingerprint, iris, face for security access |
| Backup | recover lost data |
| WPA | secures Wi-Fi |

## 4. IT Act 2000

| Fact | Detail |
|---|---|
| Enacted | 2000 (in force 17 Oct 2000), amended 2008 |
| Original size | **13 chapters**, 90 sections |
| Sec 43 | damage to computer or data |
| Sec 66 | computer-related offences / hacking |
| Sec 66C | identity theft |
| Sec 66D | cheating by personation |
| Sec 66F | cyber terrorism |
| Sec 67 | obscene material |
| Sec 66A | struck down by Supreme Court (2015) |

## 5. Intellectual Property Rights (IPR)

| Right | Protects |
|---|---|
| Copyright | books, software, music |
| Patent | inventions |
| Trademark | brand name, logo |
| Trade dress | look and feel of a product |
| Trade secret / know-how | confidential knowledge |
| Industrial design | shape, appearance |
| Geographical indication | origin-linked goods |

IPR covers all of these.

## 6. E-governance and e-commerce

| Model | Meaning |
|---|---|
| G2C | government to citizen |
| G2B | government to business |
| G2G | government to government |
| G2E | government to employee |
| B2B / B2C / C2C | business to business / consumer / consumer to consumer |
| m-commerce | commerce on mobile |

### Q458 · 🟡 Medium
**Q.** Exploiting and experimenting a telephone system ____

> [!success]- Answer
> **Phreaking**
> Phreaking = phone hacking. Phishing = fake emails. Pharming = fake websites via DNS.
> Don't confuse with: Phishing; Pharming; Prebinding

### Q719 · 🟡 Medium
**Q.** Virus designed to hide from antivirus software ____

> [!success]- Answer
> **Stealth virus**
> Stealth virus hides. Polymorphic virus CHANGES its code each time.
> Don't confuse with: Micro virus; Parasitic virus; Polymorphic virus

> [!warning] Exam Trap ⚠️
> - Stealth (hides) vs polymorphic (mutates).
> - Phishing (email) vs pharming (site) vs phreaking (phone).
> - IT Act 2000 originally had **13** chapters.
