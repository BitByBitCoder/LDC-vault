# Part 1: Learn the topic

## 1. Computer generations

| Gen | Period | Technology | Languages / features |
|---|---|---|---|
| 1st | 1940-56 | vacuum tubes | machine language. ENIAC, UNIVAC |
| 2nd | 1956-63 | transistors | assembly, FORTRAN, COBOL. **Batch processing**, line printers |
| 3rd | 1964-71 | integrated circuits | OS, multiprogramming, keyboard + monitor |
| 4th | 1971-present | microprocessor, VLSI | personal computers, GUI |
| 5th | present-future | ULSI, AI | **KIPS**, PROLOG, parallel processing |

## 2. Types of computers

| By data | How it works |
|---|---|
| Analog | measures continuous values (voltage, pressure). **Input never converted to digital** |
| Digital | works on 0 and 1 |
| Hybrid | both analog and digital (hospital ECG, petrol pump) |

| By size | Notes |
|---|---|
| Supercomputer | fastest, measured in **FLOPS** |
| Mainframe | large organisations, word length 48-64 bits |
| Minicomputer | mid-range |
| Microcomputer | PC, laptop |

## 3. Mobile generations

| Gen | Feature |
|---|---|
| 1G | analog voice |
| 2G | digital voice + **SMS** |
| 3G | mobile internet, video calls |
| 4G | LTE broadband |
| 5G | very high speed, low delay |

### Q86 · Q400 🔁 · 🟢 Easy
**Q.** In an analog computer ____

> [!success]- Answer
> **Input is never converted to digital form**
> Analog computers work on continuous physical quantities (voltage, pressure) directly, no digital conversion.
> Don't confuse with: Input is first converted to digital form; Output is displayed in digital form; None

### Q180 · 🟢 Easy
**Q.** Performance of a supercomputer is measured in ____

> [!success]- Answer
> **Floating point operations per second**
> Supercomputers = FLOPS. PCs = MIPS/GHz.
> Don't confuse with: Instructions per second; Read/Write cycles per second; I/O operations per second

### Q271 · 🟢 Easy
