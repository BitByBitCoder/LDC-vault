# 🔁 Repeated Questions (high yield)

These appeared more than once in your set. Learn these first.

### Q96 · Q382 · Q495 🔁 · 🟢 Easy
**Q.** Status register is also called ____

> [!success]- Answer
> **Flags**
> Holds condition flags (zero, carry, sign, overflow). Also called Flag register / PSW.
> Don't confuse with: Accumulator; Stack; Counter

### Q115 · Q410 · Q519 🔁 · 🟢 Easy
**Q.** Command to see the sub-directory structure of a drive ____

> [!success]- Answer
> **Tree**
> TREE. Draws the folder tree. (TREE /F also shows files.)
> Don't confuse with: List; Subdir; Subtree

### Q376 · Q486 🔁 · 🟢 Easy
**Q.** In magnetic disks, data is organised on the platter in concentric rings called ____

> [!success]- Answer
> **Track**
> Rings = tracks. Tracks are cut into sectors (pie slices).
> Don't confuse with: Sector; Head; Block

### Q95 · Q381 🔁 · 🟢 Easy
**Q.** The address bus flows ____

> [!success]- Answer
> **Unidirection**
> Address bus is ONE-WAY: CPU to memory/I/O (CPU says where). Data bus is two-way. Hook: Address = Away.
> Don't confuse with: Bidirection; Multidirection; Circular

### Q164 · Q391 🔁 · 🟢 Easy
**Q.** Register containing the address of the next instruction ____

> [!success]- Answer
> **Program counter**
> PC = address of NEXT instruction. IR = the instruction being executed now.
> Don't confuse with: Instruction register; Accumulator; Container

### Q86 · Q400 🔁 · 🟢 Easy
**Q.** In an analog computer ____

> [!success]- Answer
> **Input is never converted to digital form**
> Analog computers work on continuous physical quantities (voltage, pressure) directly, no digital conversion.
> Don't confuse with: Input is first converted to digital form; Output is displayed in digital form; None

### Q123 · Q413 🔁 · 🟡 Medium
**Q.** Fragmentation of the file system ____

> [!success]- Answer
> **can be temporarily removed by compaction**
> Defragmentation/compaction removes it temporarily; it comes back with use.
> Don't confuse with: can always be prevented; is a characteristic of all file systems; None

### Q618 · Q665 🔁 · 🟢 Easy
**Q.** Feature automating sending bulk mail / combining names and addresses with a standard document ____

> [!success]- Answer
> **mail merge**
> Mail merge = one letter + data list = many personalised letters.
> Don't confuse with: document formatting; database management; format letters

### Q698 · Q833 🔁 · 🟢 Easy
**Q.** Device that decides the path of data packets / redirects IP packets to destination ____

> [!success]- Answer
> **router**
> Router = chooses path between networks. Switch = connects devices inside a LAN.
> Don't confuse with: switch; hub; server

### Q374 · Q449 🔁 · 🟡 Medium
**Q.** Valid statement about a computer program ____

> [!success]- Answer
> **HLL must be converted to machine language**
> High-level language needs a compiler/interpreter. HLL is slower than machine code and easier to debug.
> Don't confuse with: HLL programs are faster; Errors harder to find in HLL; All
