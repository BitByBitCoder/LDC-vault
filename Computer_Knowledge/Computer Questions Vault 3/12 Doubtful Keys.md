# ⚠️ Doubtful Keys

Badly worded questions or conflicting published keys. The answer given is the most commonly accepted one. **Your official key wins.**

### Q104 · 🔴 Hard
**Q.** Generally Dynamic RAM is used as main memory because it ____

> [!success]- Answer
> **consumes less power** ⚠️
> DRAM = 1 transistor + 1 capacitor per bit: dense, cheap, low power. Refreshing (d) is a drawback, 'lower density' (c) is false, and SRAM is faster (b). Keys differ on this one; (a) is the commonly accepted answer.
> Don't confuse with: has higher speed; has lower cell density; needs refreshing circuitry

### Q254 · 🔴 Hard
**Q.** The first printer was invented by ____

> [!success]- Answer
> **None of the above** ⚠️
> Carlson = photocopier (xerography), Gestetner = stencil duplicator, Xerox = company. First printer concept is credited to Charles Babbage, so 'None'.
> Don't confuse with: Chester Carlson; David Gestetner; Xerox co.

### Q292 · 🔴 Hard

(choose from: a) HAN; b) LAN; c) VPN; d) VSN)

> [!success]- Answer

### Q710 · 🔴 Hard
**Q.** An IP address identifies a device. Statement ____  
(choose from: a) name indicates seek; b) address indicates where; c) route indicates how; d) All)

> [!success]- Answer
> **All** ⚠️
> Name = what we seek, address = where it is, route = how to get there (RFC 791). All true.
