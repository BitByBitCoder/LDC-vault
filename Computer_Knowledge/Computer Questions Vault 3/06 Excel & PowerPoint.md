# Part 1: Learn the topic

## 1. Excel

| Term | Meaning |
|---|---|
| Workbook | whole file, many worksheets |
| Worksheet | one sheet (also called spreadsheet) |
| Cell | intersection of a row and a column |
| Cell address | column letter + row number, like B5 |

| Limit | Excel 2007+ | Older |
|---|---|---|
| Rows | 1,048,576 | 65,536 |
| Columns | 16,384 (last XFD) | 256 (last IV) |

| Function | Does |
|---|---|
| SUM | total |
| AVERAGE | mean |
| MAX / MIN | largest / smallest |
| COUNT | counts numbers |
| IF | condition |
| VLOOKUP | vertical lookup |

| Shortcut | Action |
|---|---|
| **Alt + =** | AutoSum |
| F2 | edit cell |
| F4 | repeat / absolute reference |

First spreadsheet program: **VisiCalc**.

## 2. PowerPoint

| View | Shows |
|---|---|
| Normal | slide + notes |
| **Outline** | **text only** (titles and bullets) |
| Slide Sorter | thumbnails of all slides |
| Slide Show | full screen presentation |
| Notes Page | speaker notes |

| Term | Meaning |
|---|---|
| **Slide Master** | **top slide**: stores theme, layout, fonts for all slides |
| Transition | effect between slides |
| Animation | effect on objects within a slide |
| Sound files | **.wav and .mid** |
| Extensions | .pptx show, .ppsx slideshow |

F5 = start from beginning. Shift+F5 = start from current slide.

# Part 2: Past questions with answers

Answer in your head first, then open the callout. Level is shown before the answer. 🔁 = repeated in your paper. ⚠️ = doubtful key ([[12 Doubtful Keys]]).

### Q591 · 🟢 Easy
**Q.** PowerPoint view displaying only text (title and bullets) ____

> [!success]- Answer
> **Outline view**
> Outline view.
> Don't confuse with: Slide sorter; Slide view; Notes page

### Q840 · 🟢 Easy
**Q.** A collection of worksheets is called ____

> [!success]- Answer
> **Workbook**
> Workbook = file with many worksheets.
> Don't confuse with: Spreadsheet; Excel sheets; Ledger

### Q583 · 🟡 Medium
**Q.** Keyboard shortcut to insert AutoSum ____

> [!success]- Answer
> **Alt+=**
> Alt + = (equals).
> Don't confuse with: Ctrl+; Alt+#; Ctrl+Q

### Q817 · 🟡 Medium
**Q.** Top slide in hierarchy storing theme and layout information ____

> [!success]- Answer
> **Slide master**
> Slide Master.
> Don't confuse with: Slide show; Slide sorter; Template master

### Q941 · 🔴 Hard
**Q.** Two kinds of sound effect files in PowerPoint ____

> [!success]- Answer
> **.wav and .mid**
> .wav and .mid (MIDI). gif/jpg are images.
> Don't confuse with: .wav and .gif; .wav and .jpg; .giv and .gif

> [!warning] Exam Trap ⚠️
> - Workbook (file) vs worksheet (sheet) vs cell.
> - Outline view = text only. Slide Sorter = thumbnails.
> - Slide Master = top slide with theme.
