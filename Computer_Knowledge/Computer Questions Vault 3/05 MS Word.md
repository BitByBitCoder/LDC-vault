# Part 1: Learn the topic

## 1. Basics

| Term | Meaning |
|---|---|
| Word wrap | text moves to the next line **automatically** at the right edge |
| Table minimum | **1 row, 1 column** |
| Sizing handles | small squares on a selected graphic that resize it |
| Font | design of type |
| Indent | moves paragraph text away from the margin for readability |
| Margin | blank space at page edge |
| Orientation | portrait or landscape |

## 2. Proofing and formatting tools

| Tool | Does |
|---|---|
| Spelling (F7) | finds misspelt words |
| Thesaurus (Shift+F7) | **synonyms and antonyms** |
| Grammar check | grammar errors |
| AutoCorrect | replaces **misspelt** words as you type |
| Find and Replace (Ctrl+H) | correct a word everywhere at once |
| Format Painter | copies formatting to other text |
| Bookmark | marks a specific place in a document |
| Hyperlink | link to page or file |

## 3. Mail merge

| Item | Role |
|---|---|
| Main document | the standard letter |
| Data source | names and addresses list |
| Merge fields | placeholders such as Name |

Not required: "Word fields". Result: many personalised letters from one letter and one list.

## 4. Page layout terms

| Term | Meaning |
|---|---|
| **Orphan** | **first** line of a paragraph alone at the **bottom** of a page |
| **Widow** | **last** line of a paragraph alone at the **top** of next page |
| Subscript | below baseline (H2O) |
| Superscript | above baseline (x2) |
| Justified | both margins even |
| Header / footer | repeated text at top / bottom |

## 5. Shortcuts

| Keys | Action | Keys | Action |
|---|---|---|---|
| Ctrl+B | bold | Ctrl+E | centre |
| Ctrl+I | italic | Ctrl+L | left |
| Ctrl+U | underline | Ctrl+R | right |
| Ctrl+C / X / V | copy / cut / paste | Ctrl+J | justify |
| Ctrl+Z / Y | undo / redo | Ctrl+A | select all |
| Ctrl+S | save | Ctrl+P | print |
| Ctrl+F | find | Ctrl+Enter | page break |

## 6. Tips

- Autofit a column: double-click its **right** border.
- Word file extension: **.docx**. WordPad: **.rtf**.
- Many documents can be opened at once: **as many as memory can hold**.
