#computer #sw

## Concept core

- **System software** = OS, compilers, translators, drivers. **Application software** = word processor etc. **Utility** = maintenance tools.
- High-level languages need a **compiler/interpreter**. PROLOG/LISP = AI. COBOL = business. FORTRAN = science.
- **SDLC:** Requirements (WHAT) then Design (HOW), Coding, Testing, Deployment, Maintenance. CASE tools support it.
- **OOP:** polymorphism = many forms, inheritance = **reusability**.
- C variable names cannot start with a digit. `%i` and `%d` both read int.
- Data mining = extracting useful patterns from big data. Cell = intersection of row and column. DDE = data exchange between apps.
