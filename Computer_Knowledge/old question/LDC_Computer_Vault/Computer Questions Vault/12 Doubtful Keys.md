# ⚠️ Doubtful Keys

The questions below are badly worded, or published keys disagree. The answer given is the most commonly accepted one. **If you have the official key, trust it over this note.**

### Q104
Generally Dynamic RAM is used as main memory because it:

a) consumes less power  ·  b) has higher speed  ·  c) has lower cell density  ·  d) needs refreshing circuitry

||**a) consumes less power** — DRAM = 1 transistor + 1 capacitor per bit: dense, cheap, low power. Refreshing (d) is a drawback, 'lower density' (c) is false, and SRAM is faster (b). Keys differ on this one; (a) is the commonly accepted answer.||

### Q254
The first printer was invented by:

a) Chester Carlson  ·  b) David Gestetner  ·  c) Xerox co.  ·  d) None of the above

||**d) None of the above** — Carlson = photocopier (xerography), Gestetner = stencil duplicator, Xerox = company. First printer concept is credited to Charles Babbage, so 'None'.||

### Q292
Choose the odd one:

a) HAN  ·  b) LAN  ·  c) VPN  ·  d) VSN

||**d) VSN** — HAN (Home Area), LAN and VPN are real network types; VSN is not a standard term. Verify against your key.||

### Q339
What is software:

a) A set of instructions  ·  b) Set of programs  ·  c) Set of information  ·  d) None

||**a) A set of instructions** — Software = instructions that tell hardware what to do. (b) is also close; (a) is the commoner key.||

### Q418
Indentation in word processing is used to:

a) readable  ·  b) paragraph color  ·  c) apply border  ·  d) change line spacing

||**a) readable** — Indent moves paragraph text from the margin to improve readability/structure. Poorly worded; (a) is the only sensible option.||

### Q491
Which category of microprocessor instructions detect status conditions:

a) Transfer  ·  b) Operation  ·  c) Control Instructions  ·  d) All of these

||**b) Operation** — Arithmetic/logic 'operation' instructions set the status flags. Doubtful question; verify against your key.||

### Q499
First phase in SDLC:

a) Feasibility analysis  ·  b) Requirement gathering  ·  c) Design  ·  d) Coding

||**b) Requirement gathering** — SDLC: Planning/Requirements, Design, Coding, Testing, Deployment, Maintenance. Some books begin with feasibility; verify your key.||

### Q502
Phase typically consuming maximum effort among development phases:

a) Requirements  ·  b) Design  ·  c) Coding  ·  d) Testing

||**d) Testing** — Testing takes the most effort among development phases (maintenance takes the most over the whole life). Check your key.||

### Q508
Popular type of handheld computer:

a) smart phone  ·  b) PDA  ·  c) DSLR  ·  d) Laptop

||**a) smart phone** — Smartphone is the modern answer (PDA is the older textbook answer). Older keys may say PDA.||

### Q574
Latest major release of Microsoft's Windows NT operating system:

a) Windows 11  ·  b) Windows NT 4.0  ·  c) Windows XP  ·  d) Windows Vista

||**a) Windows 11** — Every modern Windows (XP onward, up to 11) is built on the NT kernel, so the newest = Windows 11.||

### Q576
Whitespace used to place text in the left margin next to the main body:

a) Indent  ·  b) Margin notes  ·  c) Break  ·  d) Orientation

||**b) Margin notes** — Margin notes. Doubtful wording; check your key.||

### Q594
Access point (AP) in a wireless LAN is:

a) device for connection  ·  b) wireless device itself  ·  c) both  ·  d) all

||**a) device for connection** — AP connects wireless devices to the wired network. Doubtful wording but (a).||

### Q635
Disk defragmentation means:

a) file stored across disks  ·  b) stored in several locations  ·  c) crashed  ·  d) none

||**b) stored in several locations** — Option (b) describes FRAGMENTATION (file scattered); the question is badly worded but (b) is the usual key.||

### Q649
E-governance uses:

a) Government  ·  b) Intranet  ·  c) Internet  ·  d) None

||**c) Internet** — E-governance delivers services over the Internet (ICT). Vague question.||

### Q672
Generation of computers that introduced connection to printers:

a) First  ·  b) Second  ·  c) Third  ·  d) Fourth

||**b) Second** — Printers (line printers) arrived with second-gen machines. Doubtful; check your key.||

### Q694
Bytes equivalent to 12 GB:

a) 1024  ·  b) 12 x 1024  ·  c) 1024 x 1024 x 1024  ·  d) 1024

||**b) 12 x 1024** — Correct maths = 12 x 1024 x 1024 x 1024 = 12,884,901,888 bytes, which is not listed. (b) is the closest/usual key.||

### Q710
An IP address identifies a device. Statement:

a) name indicates seek  ·  b) address indicates where  ·  c) route indicates how  ·  d) All

||**d) All** — Name = what we seek, address = where it is, route = how to get there (RFC 791). All true.||

### Q725
The Internet is governed by:

a) IETF  ·  b) W3C  ·  c) InterNIC  ·  d) None

||**a) IETF** — IETF (written 'IEFT' in your set) sets internet standards. Related: W3C = web standards. Verify key.||

### Q820
System software that aims to maintain and make best use of computer resources:

a) Utility  ·  b) Application  ·  c) Reservation  ·  d) None

||**d) None** — Managing and optimising resources is the job of the operating system, which is not listed. Check your key.||
