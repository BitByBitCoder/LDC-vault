# Analog, Digital & Hybrid Computers

> **Q86:** In an analog computer, input is **never converted to digital form** → answer **(b)**. Analog computers work directly on continuous physical quantities (voltage, temperature, pressure, speed).

## 1. Classification by working principle
| Type | Works on | Data form | Example |
| --- | --- | --- | --- |
| Analog | Continuous physical quantities | Voltage, current, pressure, temperature | Speedometer, thermometer, mercury barometer, seismograph, analog watch |
| Digital | Discrete data | Binary digits 0 and 1 | Desktop, laptop, smartphone, calculator |
| Hybrid | Both analog and digital | Analog input, digital processing | ICU patient monitor, petrol pump, ECG machine, radar, weather systems |

## 2. Analog vs Digital
| Point | Analog | Digital |
| --- | --- | --- |
| Data | Continuous | Discrete (0 and 1) |
| Measures | Physical quantities | Counts / numbers |
| Accuracy | Low | High |
| Speed | Faster for specific tasks | General purpose, very fast |
| Memory / storage | Little or none | Large |
| Input converted to digital? | **Never** | Yes (analog input is converted by ADC) |
| Output | Meter reading, graph, dial | Numbers, text, screen display |
| Programming | Hard, not general purpose | Programmable, general purpose |
| Cost | Costly for the task | Cheaper per function |
| Use | Specific, special purpose | General purpose |

## 3. Hybrid computer
| Point | Detail |
| --- | --- |
| Definition | Combines features of analog and digital computers |
| Conversion | ADC (analog to digital) at input, DAC (digital to analog) at output |
| Analog part | Measures / senses physical quantity |
| Digital part | Processes, calculates, stores |
| Used in | Hospitals (ICU, ECG), petrol pumps, aircraft, weather forecasting, industrial control |

## 4. Classification by size
| Type | Notes | Example |
| --- | --- | --- |
| Supercomputer | Fastest, most powerful, millions of calculations/sec | PARAM (India), Cray, Summit |
| Mainframe | Large, many users at once | IBM Z series |
| Minicomputer | Medium size, multi-user | PDP-11, VAX |
| Microcomputer | Single user, uses a microprocessor | PC, laptop |

## 5. Classification by purpose
| Type | Meaning |
| --- | --- |
| General purpose | Does many tasks (PC) |
| Special purpose | Built for one task (washing machine chip, ATM) |

## 6. Key terms
| Term | Meaning |
| --- | --- |
| ADC | Analog to Digital Converter |
| DAC | Digital to Analog Converter |
| Modem | Modulator-Demodulator: converts digital ↔ analog signals over phone lines |
| Binary | Number system with only 0 and 1 |
| Bit | Binary digit, smallest unit of data |
| Discrete | Separate countable values |
| Continuous | Smoothly varying values |

## 8. Exam tip
- Analog = **measures**; Digital = **counts**; Hybrid = **both**.
- "Analog … input converted to digital?" → always **No / never**.
- Hybrid examples to remember: **petrol pump, hospital ICU, ECG**.
