## Concept core

| Gen | Technology | Notes |
|---|---|---|
| 1st | Vacuum tubes | ENIAC, UNIVAC, machine language |
| 2nd | Transistors | **batch processing**, assembly, COBOL/FORTRAN, line printers |
| 3rd | Integrated circuits | OS, multiprogramming, keyboard + monitor |
| 4th | Microprocessor / VLSI | PCs |
| 5th | AI / ULSI | **KIPS**, PROLOG |

**Mobile:** 1G analog voice, **2G digital + SMS**, 3G data/video, 4G LTE broadband.

**Computer types:** Analog (continuous, never converted), Digital, **Hybrid** (both).

**Names to link:** Babbage = father of computer · **McCarthy = AI** · **Vint Cerf = Internet** · Haartsen = Bluetooth · Charley Kline = first ARPANET message · EDSAC = first stored program · **VisiCalc** = first spreadsheet · **Mosaic** = first graphical browser · **Creeper** = first ARPANET virus · Saga-220/Param/Eka = Indian supercomputers (Mira, Titan = USA).

### Q86 · Q400 🔁 · 🟢 Easy
In an analog computer:  
a) Input is first converted to digital form  
b) Input is never converted to digital form  
c) Output is displayed in digital form  
d) None

> [!success]- Answer
> **b) Input is never converted to digital form**
> Analog computers work on continuous physical quantities (voltage, pressure) directly, no digital conversion.
