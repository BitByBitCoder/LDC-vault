# Excel & PowerPoint

#computer #xls

**5 questions** · 🟢 2 · 🟡 2 · 🔴 1

## Concept core

- Excel: file = **Workbook**, tabs = worksheets. AutoSum = **Alt + =**.
- PowerPoint: **Outline view** = text only. **Slide Master** = top slide holding theme/layout. Sound files: **.wav and .mid**.
