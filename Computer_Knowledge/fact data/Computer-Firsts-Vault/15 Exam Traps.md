# 15 Exam Traps - same question, different keys

Back to [[00 Index]].

Exam keys (SSC, banking, state PSC/LDC style papers) sometimes follow older textbooks. When more than one answer is defensible, **read the qualifier** (*practical, commercial, programmable, electronic, general-purpose, first popular*) and **look at the options** before choosing.

## 1. First computer to store its program
| If the question says... | Answer |
|---|---|
| first to *run* a stored program | Manchester Baby (SSEM), 1948 |
| first *practical* / regular-service stored-program computer | EDSAC, 1949 |
| *concept* / design / von Neumann | EDVAC |
| Only EDSAC and EDVAC (plus ENIAC, UNIVAC) are options | EDSAC is the usual key; EDVAC appears in some older keys |

## 2. First electronic computer
| Wording | Answer |
|---|---|
| first electronic digital computer | ABC (Atanasoff-Berry) |
| first programmable electronic computer | Colossus |
| first general-purpose electronic computer | ENIAC |
| first programmable fully automatic digital computer | Zuse Z3 |
| first electromechanical computer | Harvard Mark I |
If ABC is not among the options and the question just says 'first electronic computer', the key is usually ENIAC.

## 3. Father of Computer vs Father of Modern Computer
- Father of Computer: **Charles Babbage**.
- Father of Modern Computer: **John von Neumann** (architecture) *or* **Alan Turing** (theory). Pick whichever appears; if both appear, von Neumann for 'architecture / stored program', Turing for 'theory / AI'.

## 4. First personal computer
Kenbak-1 (1971) is the earliest widely cited; Altair 8800 (1975) is the first *successful* one; IBM PC 5150 (1981) is IBM's first and set the standard.

## 5. First laptop
Osborne 1 (1981, portable/luggable), Epson HX-20 (1981, handheld), GRiD Compass (1982, first true clamshell laptop). Choose from the options given.

## 6. First operating system
GM-NAA I/O (1956) is the usual 'first OS' answer; Unix (1969) is the famous early one; CP/M (1974) for microcomputers; MS-DOS (1981) for the IBM PC.

## 7. First programming language
- First *designed* high-level language: Plankalkul (Zuse).
- First *widely used* high-level language: **FORTRAN (1957)**.
- First compiler: A-0 (Grace Hopper, 1952).
- First OOP language: Simula; first pure OOP: Smalltalk.

## 8. First computer virus
Creeper (1971, experimental), Elk Cloner (1982, first microcomputer virus in the wild), **Brain (1986, first IBM PC virus)**, Morris worm (1988, first Internet worm).

## 9. First web browser
WorldWideWeb (1990) is the very first; Mosaic (1993) is the first *popular graphical* browser; Netscape (1994); Internet Explorer (1995).

## 10. When was the Internet born?
ARPANET first message 1969; TCP/IP adopted 1 January 1983; WWW 1989-91. 'Birth of the Internet' = 1969 (ARPANET) in most keys, 1983 in others.

## 11. First smartphone
IBM Simon (1994); iPhone (2007) popularised it; first Android phone HTC Dream (2008).

## 12. First email vs first webmail
Email: Ray Tomlinson (1971). Webmail: Hotmail (1996, Sabeer Bhatia).

## 13. First search engine
Archie (1990). Google (1998) is not the first.

## 14. First computer in India
HEC-2M at ISI Kolkata (1956; some say arrival 1953) = first computer. TIFRAC (TIFR, 1960) and ISIJU-1 (1966) are the indigenous ones.

## 15. First supercomputer
CDC 6600 (1964, Seymour Cray) is the first; Cray-1 (1976) is the first commercially successful one. India's first: PARAM 8000 (1991).

## 16. Generation dates
Books differ (e.g. 1940-56 vs 1946-59). Match the **technology**: tubes, transistors, ICs, microprocessors, AI.
