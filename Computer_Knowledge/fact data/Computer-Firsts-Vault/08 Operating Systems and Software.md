# Operating Systems and Software Firsts

Back to [[00 Index]] · [[Priority - High]] · [[Priority - Medium]] · [[Priority - Low]]

Windows release dates, Unix/Linux, VisiCalc and office software.

## Questions (important first)

| Priority | Question | Answer | Note |
|---|---|---|---|
| 🔴 High | First operating system (commonly cited)? | **GM-NAA I/O (1956)** | General Motors Research and North American Aviation, for the IBM 704 |
| 🔴 High | Who created Unix? | **Ken Thompson and Dennis Ritchie (Bell Labs, 1969)** |  |
| 🔴 High | Who created Linux? | **Linus Torvalds (1991)** | First release 17 September 1991; kernel only - GNU tools by Richard Stallman |
| 🔴 High | First spreadsheet program? | **VisiCalc (1979)** | Dan Bricklin and Bob Frankston, for the Apple II |
| 🔴 High | Microsoft Windows 1.0 released? | **20 November 1985** |  |
| 🔴 High | MS-DOS came with? | **IBM PC (1981)** | Microsoft bought 86-DOS (QDOS) from Seattle Computer Products - Tim Paterson |
| 🔴 High | Windows 95 launched? | **24 August 1995** | Introduced the Start menu and taskbar |
| 🟡 Medium | First word processor for microcomputers? | **Electric Pencil (1976)** | WordStar (1978) was the first popular one |
| 🟡 Medium | Microsoft Word first released? | **1983** | Charles Simonyi and Richard Brodie |
| 🟡 Medium | Microsoft Excel first released? | **1985 (Macintosh); Windows version 1987** |  |
| 🟡 Medium | CP/M creator? | **Gary Kildall (Digital Research, 1974)** | First widely used OS for microcomputers |
| 🟡 Medium | GNU Project founder? | **Richard Stallman (1983); Free Software Foundation 1985** |  |
| 🟡 Medium | Windows XP release? | **25 October 2001** |  |
| 🟡 Medium | Windows 10 release? | **29 July 2015** | Windows 11: 5 October 2021 |

| 🟡 Medium | PDF developed by? | **Adobe (John Warnock), 1993** |  |

| 🟢 Low | Chrome OS released? | **2011** |  |
| 🟢 Low | Multics? | **1964-69, MIT / GE / Bell Labs; inspired Unix** |  |
| 🟢 Low | Lotus 1-2-3? | **1983 spreadsheet that overtook VisiCalc** |  |
