# Stored-Program Computers (first computer to store its program)

Back to [[00 Index]] · [[Priority - High]] · [[Priority - Medium]] · [[Priority - Low]]

**Stored-program idea:** instructions and data sit in the *same* memory, so a computer can be re-programmed without rewiring. Before this (ENIAC) programs were set with cables and switches.

**Quick answer sheet**
- Concept / design: **EDVAC** (John von Neumann's 1945 report)
- First to actually run a stored program: **Manchester Baby (SSEM)**, 21 June 1948
- First practical stored-program computer: **EDSAC**, May 1949
- Exam keys differ on this one, so read [[15 Exam Traps]] before the exam.

| 🟡 Medium | First commercial computer in the USA built on the stored-program idea? | **UNIVAC I (1951)** |  |

| 🟢 Low | First program run on EDSAC? | **Printing a table of squares (and a list of primes)** | 6 May 1949 |
