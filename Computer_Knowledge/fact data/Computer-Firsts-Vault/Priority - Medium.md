## [[01 Stored-Program Computers]]

- Full form of SSEM? → **Small-Scale Experimental Machine**
- Who built the Manchester Baby? → **Frederic C. Williams, Tom Kilburn and Geoff Tootill**
- Memory used by the Manchester Baby? → **Williams-Kilburn tube**
- Memory used by EDSAC? → **Mercury delay lines**
- Main idea of von Neumann architecture? → **Instructions and data share one memory; CPU fetches, decodes, executes**
- Architecture with separate memories for instructions and data? → **Harvard architecture**
- First commercial computer in the USA built on the stored-program idea? → **UNIVAC I (1951)**
- Assembly language was first used on which machine? → **EDSAC (1949)**

## [[04 Computer Generations]]

- Which generation introduced the operating system and multiprogramming? → **Third**
- Which generation introduced the stored-program concept? → **First (EDSAC/EDVAC era)**
- Main memory in each generation? → **1st: magnetic drum / delay line; 2nd: magnetic core; 3rd: semiconductor memory; 4th: semiconductor RAM (VLSI)**
- Second-generation computers used which languages? → **Assembly language plus early high-level languages (FORTRAN, COBOL)**
- Example machines of the 2nd generation? → **IBM 1401, IBM 7090/7094, CDC 1604**
- Example machines of the 3rd generation? → **IBM 360/370, PDP-8, PDP-11**
- Example machines of the 4th generation? → **Altair 8800, Apple II, IBM PC, Cray-1**
- Which generation brought the GUI and mouse to the mass market? → **Fourth**
