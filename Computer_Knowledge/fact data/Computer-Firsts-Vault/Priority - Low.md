# Priority - Low 🟢 

Rarely asked but possible in harder papers.

Back to [[00 Index]]

**70 facts**


## [[01 Stored-Program Computers]]

- First program run on the Manchester Baby? → **Finding the highest proper factor of 2^18 (answer 131072)**
- First program run on EDSAC? → **Printing a table of squares (and a list of primes)**

## [[02 Early Calculating Devices]]

- Oldest known analog computer? → **Antikythera mechanism (Greece, about 2nd-1st century BC)**
- First general-purpose analog computer (1931)? → **Differential Analyzer, Vannevar Bush (MIT)**
- Who linked Boolean algebra to electrical switching circuits (1937)? → **Claude Shannon**
- Earliest use of perforated paper to control a loom (1725)? → **Basile Bouchon**

## [[03 Early Electronic Computers]]

- ENIAC's main task? → **Computing artillery firing tables for the US Army**
- Size of Harvard Mark I? → **About 51 feet (15 m) long**
- 1973 US court ruling about the ENIAC patent? → **Invalidated it; Atanasoff's earlier ABC work was recognised**

## [[04 Computer Generations]]

- Drawbacks of first-generation computers? → **Large, hot, power-hungry, short-lived tubes, machine language only**
- Why do generation dates differ between books? → **Authors draw the boundaries differently (e.g. 1946-59 for the first generation in some texts)**

## [[05 Hardware Firsts]]

- Barcode patent (1952)? → **Norman Woodland and Bernard Silver**
- First LCD? → **George Heilmeier (RCA, 1968)**
- Touchscreen inventor (1965)? → **E. A. Johnson (UK)**
- First webcam? → **Trojan Room coffee pot camera, Cambridge (1991)**
- DVD and Blu-ray introduced? → **DVD 1995-96 (Toshiba, Panasonic, Philips, Sony); Blu-ray 2006 (Sony)**

## [[06 PCs Laptops and Mobiles]]

- Toshiba T1100 (1985)? → **First mass-market laptop**
- Olivetti Programma 101 (1965)? → **Often called the first desktop computer (programmable calculator)**

## [[07 Programming Languages]]

- ALGOL? → **Algorithmic Language (1958/60); first block-structured language; introduced BNF notation**
- Perl? → **Larry Wall (1987)**
- PHP? → **Rasmus Lerdorf (1994-95)**
- Ruby? → **Yukihiro Matsumoto (1995)**
- C# creator? → **Anders Hejlsberg (Microsoft, announced 2000)**
- Go language? → **Google (2009); Robert Griesemer, Rob Pike, Ken Thompson**
- Swift? → **Apple (2014)**
- Logo and turtle graphics? → **Seymour Papert (1967)**
- Prolog? → **Alain Colmerauer (1972)**
- Plankalkul? → **Konrad Zuse, designed 1942-45; first designed high-level language**
- Autocode? → **Alick Glennie (1952); first compiled language (Manchester Mark 1)**
- CSS first specification? → **1996 (proposed 1994 by Hakon Wium Lie)**

## [[08 Operating Systems and Software]]

- PowerPoint created by? → **Robert Gaskins and Dennis Austin (1987); bought by Microsoft the same year**
- First commercial relational database? → **Oracle (Larry Ellison, 1979)**
- Photoshop created by? → **Thomas and John Knoll (1988); Adobe bought it in 1989**
- Chrome OS released? → **2011**
- Multics? → **1964-69, MIT / GE / Bell Labs; inspired Unix**
- Lotus 1-2-3? → **1983 spreadsheet that overtook VisiCalc**
- Mac OS X? → **2001**

## [[09 Internet and Web]]

- WhatsApp founded? → **2009 by Jan Koum and Brian Acton**
- Instagram founded? → **2010 by Kevin Systrom and Mike Krieger**
- LinkedIn launched? → **2003 (Reid Hoffman)**
- Telegram launched? → **2013 (Pavel Durov)**
- Amazon? → **Founded 1994 by Jeff Bezos as an online bookstore; site opened July 1995**
- First banner ad? → **1994 (AT&T on HotWired)**
- First spam email? → **1978, Gary Thuerk (DEC)**
- W3C founded? → **1994 by Tim Berners-Lee**
- Gopher? → **1991, University of Minnesota**
- WWW placed in the public domain by CERN? → **30 April 1993**

## [[10 Viruses and Security]]

- Term 'phishing'? → **1996 (AOL)**
- Code Red? → **2001 worm**
- India's first dedicated data protection law? → **Digital Personal Data Protection Act, 2023**

## [[11 AI Robots and Games]]

- OXO? → **1952, first graphical computer game, on EDSAC**
- Shakey? → **First mobile robot that reasoned about its actions (SRI, 1966-72)**
- Pac-Man? → **1980 (Namco)**
- PARRY? → **1972 chatbot simulating a person with paranoia**

- Shakti? → **Indigenous RISC-V processor family from IIT Madras (2018)**
