# Personal Computers, Laptops and Mobile Phones

Back to [[00 Index]] · [[Priority - High]] · [[Priority - Medium]] · [[Priority - Low]]

Personal computer, GUI, laptop and mobile-phone firsts. Several have more than one defensible answer - see [[15 Exam Traps]].

## Questions (important first)

| Priority | Question | Answer | Note |
|---|---|---|---|
| 🔴 High | First personal computer (widely cited)? | **Kenbak-1 (1971)** | John Blankenbaker; about 130 built. See [[15 Exam Traps]] |
| 🔴 High | First commercially successful personal computer? | **Altair 8800 (1975)** | MITS, Ed Roberts; Intel 8080; Microsoft was founded to write its BASIC |
| 🔴 High | IBM PC (model 5150) launched? | **12 August 1981** | Intel 8088, MS-DOS; made 'PC' a standard |
| 🔴 High | Apple I (1976) was built by? | **Steve Wozniak (with Steve Jobs)** | Apple II followed in 1977 |
| 🔴 High | First computer with a GUI and mouse? | **Xerox Alto (1973)** | Xerox PARC; Xerox Star (1981) was the first commercial GUI system |
| 🔴 High | First mass-market computer with a GUI and mouse? | **Apple Macintosh (24 January 1984)** | Apple Lisa (1983) came first but sold poorly |
| 🔴 High | First mobile phone call? | **3 April 1973, Martin Cooper (Motorola) using the DynaTAC** | Called rival Joel Engel at Bell Labs |
| 🔴 High | First commercially available handheld mobile phone? | **Motorola DynaTAC 8000X (1983)** |  |
| 🔴 High | First smartphone? | **IBM Simon (1994)** | Apple iPhone launched 2007; first Android phone HTC Dream 2008 |
| 🔴 High | First laptop (most cited)? | **Osborne 1 (1981) as first portable; GRiD Compass (1982) as first true clamshell laptop** | Epson HX-20 (1981) is also called the first laptop - see [[15 Exam Traps]] |
| 🟡 Medium | First SMS (text message)? | **3 December 1992, 'Merry Christmas', sent by Neil Papworth** | Vodafone, UK |
| 🟡 Medium | First commercial microcomputer using a microprocessor? | **Micral N (France, 1973)** |  |
| 🟡 Medium | Who invented the Ctrl+Alt+Del combination? | **David Bradley (IBM, 1981)** |  |
| 🟡 Medium | iPhone announced by? | **Steve Jobs, 9 January 2007** | Released 29 June 2007 |
| 🟡 Medium | Compaq Portable (1982)? | **First successful IBM PC-compatible** | Started the PC clone market |
| 🟡 Medium | Who founded Android Inc. and who bought it? | **Andy Rubin (2003); Google bought it in 2005** |  |
| 🟢 Low | Toshiba T1100 (1985)? | **First mass-market laptop** |  |
| 🟢 Low | Olivetti Programma 101 (1965)? | **Often called the first desktop computer (programmable calculator)** |  |
