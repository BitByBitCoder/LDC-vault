# Early Electronic Computers (1940s-1960s)

Back to [[00 Index]] · [[Priority - High]] · [[Priority - Medium]] · [[Priority - Low]]

Know the exact qualifier: *electronic* vs *electromechanical*, *digital*, *programmable*, *general-purpose*, *commercial*. See [[15 Exam Traps]].

## Questions (important first)

| Priority | Question | Answer | Note |
|---|---|---|---|
| 🔴 High | First general-purpose electronic digital computer? | **ENIAC (completed 1945, unveiled 1946)** | Built by J. Presper Eckert and John Mauchly at the University of Pennsylvania |
| 🔴 High | Full form of ENIAC? | **Electronic Numerical Integrator And Computer** |  |
| 🔴 High | ENIAC used which technology? | **Vacuum tubes (about 18,000)** | Weighed about 30 tons; a first-generation machine |
| 🔴 High | First electronic digital computer? | **Atanasoff-Berry Computer (ABC), 1937-42** | John V. Atanasoff and Clifford Berry, Iowa State; special-purpose, not programmable |
| 🔴 High | First programmable, fully automatic digital computer? | **Zuse Z3 (1941)** | Konrad Zuse, Germany; used electromechanical relays |
| 🔴 High | First programmable electronic digital computer? | **Colossus (1943-44)** | Tommy Flowers, Bletchley Park; used to break the German Lorenz cipher |
| 🔴 High | First electromechanical computer? | **Harvard Mark I (1944)** | Howard Aiken with IBM; official name Automatic Sequence Controlled Calculator (ASCC) |
| 🔴 High | First commercial computer in the USA? | **UNIVAC I (1951)** | Eckert and Mauchly; delivered to the US Census Bureau; first to use magnetic tape |
| 🔴 High | Full form of UNIVAC? | **Universal Automatic Computer** |  |
| 🟡 Medium | First commercially available general-purpose electronic computer (UK)? | **Ferranti Mark 1 (1951)** | Delivered to Manchester University; based on the Manchester Mark 1 |
| 🟡 Medium | First computer used for routine business office work? | **LEO I (1951)** | Lyons Electronic Office, built for J. Lyons and Co. (tea shops) |
| 🟡 Medium | First real-time computer (and early user of core memory)? | **Whirlwind I (MIT, 1951)** | Jay Forrester developed magnetic-core memory for it |
| 🟡 Medium | First mass-produced computer? | **IBM 650 (1954)** | About 2,000 units built |
| 🟡 Medium | IBM's first commercial scientific computer? | **IBM 701 (1952)** | Also called the Defense Calculator |
| 🟡 Medium | First transistorized computer? | **Manchester Transistor Computer (1953)** | Some keys give TRADIC (Bell Labs, 1954) or TX-0 (MIT, 1956) |
| 🟡 Medium | First family of compatible computers (third generation)? | **IBM System/360 (1964)** |  |
| 🟡 Medium | Which computer predicted the 1952 US presidential election result? | **UNIVAC I** | Correctly called Eisenhower's win on live TV |
| 🟡 Medium | First supercomputer? | **CDC 6600 (1964)** | Designed by Seymour Cray; the Cray-1 (1976) was the first commercially successful one |
| 🟡 Medium | First commercially successful minicomputer? | **DEC PDP-8 (1965)** | Digital Equipment Corporation, Ken Olsen |
| 🟡 Medium | Who were the original ENIAC programmers? | **Six women: Kay McNulty, Betty Jennings, Betty Snyder, Marlyn Wescoff, Fran Bilas, Ruth Lichterman** |  |
| 🟢 Low | ENIAC's main task? | **Computing artillery firing tables for the US Army** |  |
| 🟢 Low | Size of Harvard Mark I? | **About 51 feet (15 m) long** |  |
| 🟢 Low | 1973 US court ruling about the ENIAC patent? | **Invalidated it; Atanasoff's earlier ABC work was recognised** | Honeywell v. Sperry Rand |
