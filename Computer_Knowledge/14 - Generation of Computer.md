## 1. Overview

|Generation|Period|Key technology|Main memory|Software / languages|Examples|
|---|---|---|---|---|---|
|**First**|1940-1956|Vacuum tubes|Magnetic drum, delay line, Williams tube|Machine language (binary)|ENIAC, EDVAC, EDSAC, UNIVAC I, IBM 650, IBM 701|
|**Second**|1956-1963|Transistors|Magnetic core|Assembly language, early FORTRAN and COBOL|IBM 1401, IBM 7090/7094, CDC 1604|
|**Third**|1964-1971|Integrated circuits (IC)|Semiconductor memory|Operating systems, high-level languages (BASIC, Pascal, C came later)|IBM System/360, PDP-8, PDP-11|
|**Fourth**|1971-present|Microprocessors (LSI / VLSI)|Semiconductor RAM, then flash and optical|C, C++, Java, GUI software|Altair 8800, Apple II, IBM PC, Cray-1|
|**Fifth**|Present and beyond|ULSI, AI, parallel processing, quantum|Very large RAM, SSD, cloud|AI and natural-language programming|Expert systems, robots, AI assistants|

## 2. Characteristics

|Generation|Size|Speed|Reliability|Heat and power|Input / output|
|---|---|---|---|---|---|
|First|Room-sized|Milliseconds|Low (tubes burnt out often)|Very high|Punched cards, paper tape; printouts|
|Second|Much smaller|Microseconds|Better|Lower|Punched cards, magnetic tape and disk|
|Third|Minicomputers|Nanoseconds; about a million instructions/s|Good|Low|Keyboard and monitor introduced|
|Fourth|Desktops, laptops|Nanoseconds to picoseconds|High|Low|Mouse, GUI, networking|
|Fifth|Portable and cloud based|Highest|Very high|Low|Voice, touch, gesture|

## 3. Key milestone of each generation

|Generation|Milestone|Person / place|
|---|---|---|
|First|Stored-program concept|John von Neumann (1945); EDSAC 1949|
|Second|Transistor replaces the vacuum tube|Bardeen, Brattain, Shockley, Bell Labs (1947)|
|Third|Integrated circuit; operating systems and time-sharing|Jack Kilby (1958), Robert Noyce (1959)|
|Fourth|Microprocessor; personal computer|Intel 4004 (1971)|
|Fifth|Artificial intelligence|Japan's Fifth Generation project (1982)|

## 4. Do not confuse with language generations

|Language generation|Type|Example|
|---|---|---|
|1GL|Machine language|Binary 0s and 1s|
|2GL|Assembly language|Mnemonics|
|3GL|High-level language|FORTRAN, COBOL, C|
|4GL|Query / report languages|SQL|
|5GL|AI and logic languages|Prolog|

## 5. Storage in each generation

|Generation|Primary (main) memory|Secondary storage|
|---|---|---|
|First|Magnetic drum, mercury delay line, Williams-Kilburn tube|Punched cards, paper tape, magnetic tape (UNIVAC I, 1951)|
|Second|Magnetic core|Magnetic tape, magnetic disk (IBM RAMAC hard disk, 1956)|
|Third|Semiconductor memory (IC based RAM and ROM)|Magnetic disk, floppy disk (IBM, 1971), tape|
|Fourth|Semiconductor RAM (DRAM), cache|Hard disk, floppy, CD (1982), DVD, USB flash drive (2000), SSD|
|Fifth|Very large RAM|SSD, flash, cloud storage; quantum and DNA storage under research|

## 6. Software and uses in each generation

|Generation|Software|Main uses|
|---|---|---|
|First|Machine-language programs; no operating system (operators loaded jobs by hand)|Scientific calculation, artillery tables, census, code breaking|
|Second|Assembly language, early FORTRAN and COBOL, batch processing|Business data processing (payroll, billing), scientific and atomic-energy work|
|Third|Operating systems (OS/360), time-sharing, multiprogramming, BASIC and Pascal|Banking, airline reservations, universities, laboratories|
|Fourth|GUI operating systems (Windows, Mac OS, Linux), word processors, spreadsheets, databases, browsers|Homes, offices, schools, Internet, games, multimedia|
|Fifth|AI and machine-learning software, voice assistants, expert systems|Robotics, speech recognition, medical diagnosis, self-driving vehicles, data science|

## 7. Performance in each generation

|Generation|Time per operation (textbook key)|Typical speed|Example|
|---|---|---|---|
|First|Milliseconds (10^-3 s)|Thousands of operations per second|ENIAC: about 5,000 additions per second|
|Second|Microseconds (10^-6 s)|Hundreds of thousands per second|IBM 7090|
|Third|Nanoseconds (10^-9 s)|About a million instructions per second (1 MIPS)|IBM System/360; CDC 6600 reached about 3 million floating-point operations/s|
|Fourth|Nanoseconds to picoseconds (10^-12 s)|Millions to billions of instructions per second|Intel 4004 ran at 740 kHz (1971); IBM PC 4.77 MHz (1981); Pentium 60-66 MHz (1993); Cray-1 about 160 MFLOPS (1976)|
|Fifth|Picoseconds and below|Teraflops to exaflops (supercomputers)|Frontier (USA, 2022) was the first exascale supercomputer|

**Units of performance**

| Measure                    | Meaning                                                            |
| -------------------------- | ------------------------------------------------------------------ |
| Clock speed (Hz, MHz, GHz) | Cycles per second of the CPU clock                                 |
| MIPS                       | Millions of instructions per second                                |
| FLOPS                      | Floating-point operations per second (mega, giga, tera, peta, exa) |
|                            |                                                                    |



> [!warning] Textbooks differ Many Indian textbooks and MCQ keys give the fourth generation as picoseconds; others say nanoseconds. If only one of the two appears in the options, pick it. The order is always milliseconds → microseconds → nanoseconds → picoseconds as speed rises.

## Exam tips

- Year ranges differ between books (for example 1946-59 for the first generation in some). Match the **technology**, not the exact years.
- The **operating system** and **multiprogramming** arrived in the third generation.
- The **GUI and mouse** reached the mass market in the fourth generation.

## Check before the exam

The years and names above follow your textbook page. Other sources differ in a few places, so watch for these:

|Item|Your book says|Other sources say|
|---|---|---|
|Abacus|1602, Tim Cranmer|Used from about 2400 BCE in Babylon/Mesopotamia; the 2400 BCE date is the safe answer|
|Tabulating Machine|1884|Hollerith's machine was used in the 1890 US census (patent 1887)|
|ABC|1939|Designed 1937, working 1942; first _electronic digital_ computer|
|EDVAC vs EDSAC|EDVAC first, EDSAC second stored-program computer|Manchester Baby (1948) was first to _run_ a stored program; EDSAC (1949) was working before EDVAC. See [[15 Exam Traps]]|

If your exam follows this textbook, use the book's answer; if a past paper for your exam shows a different key, trust that paper.

## One-line memory aids

- **Calculators:** Napier (bones) → Pascal (adds) → Leibniz (multiplies)
- **Babbage:** Difference Engine (tables) → Analytical Engine (general-purpose)
- **Electronic firsts:** ABC (electronic digital) → ENIAC (general-purpose) → EDVAC/EDSAC (stored program) → UNIVAC (commercial)
- **Chips:** Intel 4004 (1971, microprocessor) → Apple II (1977) → CRAY-1 (supercomputer)
