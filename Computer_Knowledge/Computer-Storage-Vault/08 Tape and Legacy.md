# 08 · Magnetic Tape and Legacy Storage

## Magnetic tape
- Plastic ribbon coated with magnetic material, on reels or cartridges.
- **Sequential access only** (must wind to the position). Slow to find data.
- **Cheapest per GB**, huge capacity, long life. Used for **backup and archival**.
- Modern standard: **LTO (Linear Tape-Open)**. LTO-9 holds about 18 TB native.
- Drive: **tape drive / streamer**.

## Floppy disk
| Size | Capacity |
|------|----------|
| 8 inch | ~80 KB to 1 MB (first) |
| 5.25 inch | 360 KB / 1.2 MB |
| **3.5 inch** | 720 KB / **1.44 MB** (most famous) |

- Invented by **IBM** (1971). Magnetic, direct access, removable, now obsolete.

## Other legacy
| Device | Fact |
|--------|------|
| **Punched card** | Earliest storage. **Herman Hollerith** (census 1890). 80 columns |
| **Paper tape** | Strip with holes |
| **Magnetic drum** | Early primary memory |
| **Magnetic core memory** | Tiny rings, early RAM, non-volatile |
| **Bubble memory** | Obsolete |
| **Zip disk** | Iomega, 100 MB |
| **Jaz** | Iomega, 1 GB+ |

## Access methods
| Method | Device |
|--------|--------|
| **Sequential** | Magnetic tape |
| **Direct / Random** | RAM, HDD, SSD, optical, floppy |
