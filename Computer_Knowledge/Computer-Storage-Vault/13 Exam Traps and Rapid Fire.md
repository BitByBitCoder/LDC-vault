# 13 · Exam Traps and Rapid Fire

## ⚠️ Swapped-fact pairs (contrast them)
| Confusable pair | Fact A | Fact B |
|-----------------|--------|--------|
| SRAM vs DRAM | SRAM: cache, fast, no refresh | DRAM: main RAM, cheap, refresh |
| EPROM vs EEPROM | EPROM: UV light | EEPROM: electricity |
| PROM vs EPROM | PROM: once only | EPROM: erasable |
| PC vs IR | PC: **next** instruction address | IR: **current** instruction |
| CD-R vs CD-RW | Write once | Rewritable |
| SDHC vs SDXC | 4 to 32 GB | Above 32 GB to 2 TB |
| NAS vs SAN | File level | Block level |
| Seek vs access time | Seek: move head to track | Access: seek + latency |
| RAID 0 vs RAID 1 | Speed, no safety | Mirror, safety |
| CMOS vs BIOS | CMOS: RAM + battery, settings | BIOS: firmware, start-up code |
| Bit vs Byte | 1 binary digit | 8 bits |
| Primary vs secondary | RAM, ROM, cache, registers | HDD, SSD, CD, pen drive |
| Sequential vs direct | Tape | HDD, RAM, SSD, CD |
