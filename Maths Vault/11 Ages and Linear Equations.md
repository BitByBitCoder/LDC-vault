# Ages and Linear Equations

> [!abstract] 🟡 MEDIUM · ≈4% of arithmetic questions · Target accuracy **85%+** · Budget **0.5 day**
> Word problems that reduce to one or two equations. Define the unknown as the **present** value.

## Core formulas

| Concept | Formula | Quick example / shortcut |
|---|---|---|
| Age shift | Add/subtract the **same** years to everyone |  |
| Two unknowns | Substitute from the simpler equation |  |
| Quadratic | ax² + bx + c = 0 → factorise | 3x² + 10x − 8 = (3x − 2)(x + 4) |

## Visual

```text
  Now       5 yrs ago    9 yrs later
  x           x − 5         x + 9
  (x−5)(x+9) = 51  →  x² + 4x − 96 = 0  →  x = 8
```

## Exam Trap ⚠️

> [!warning] Exam Trap ⚠️
> - Ages: define the **present** age as x, then shift both by the same years.
> - 'Twice as rich after giving' — the giver's amount **drops** by the gift.
> - Quadratic: check both roots against the context (age can't be negative).
