# Simplification Surds and Indices

> [!abstract] 🟡 MEDIUM · ≈6% of arithmetic questions · Target accuracy **85%+** · Budget **1 day**
> Fast marks if BODMAS and 'of' are respected. Three questions here have **'None of the above'** as the true answer.

## Core formulas

| Concept | Formula | Quick example / shortcut |
|---|---|---|
| BODMAS | Brackets → Of → Division → Multiplication → Add → Subtract | 'of' binds before ÷ |
| Surds | a√x ± b√x = (a ± b)√x | √50 = 5√2 |
| (a+b)² − (a−b)² | 4ab | (√3+√2)² − (√3−√2)² = 4√6 |
| Indices | aᵐ·aⁿ = aᵐ⁺ⁿ ; aᵐ/aⁿ = aᵐ⁻ⁿ | 2^(1/3)·2^(2/3) = 2 |
| Nested root | √(k + √(k + …)) = x → x² = k + x | k = 72 → 9 |
| Terminating decimal | 24/100 → reduce | 0.24 = 6/25 |

## Visual

```text
 x = √(72 + √(72 + √(72 + …)))
 x = √(72 + x)   →   x² − x − 72 = 0   →   (x − 9)(x + 8) = 0   →   x = 9
```

## Exam Trap ⚠️

> [!warning] Exam Trap ⚠️
> - '**of**' binds tighter than ÷ and ×: '6 × (1/3) of 12' = 6 × 4.
> - Check for **'None of the above'** — it is the correct answer in some questions.
> - Combine **like surds only**: √2 and √3 never merge.
> - Skipped for source errors: '4/9 × x = 7/9 − (…)' (answer not in options).
