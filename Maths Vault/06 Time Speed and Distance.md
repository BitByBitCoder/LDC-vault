# Time Speed and Distance

> [!abstract] 🔴 HIGH · ≈8% of arithmetic questions · Target accuracy **90%+** · Budget **1.5 days**
> Trains, boats and unit conversions. ×5/18 and ×18/5 should be reflex.

## Core formulas

| Concept | Formula | Quick example / shortcut |
|---|---|---|
| km/h → m/s | × 5/18 | 72 → 20 |
| m/s → km/h | × 18/5 | 100 → 360 |
| Train crossing pole | Time = L / speed |  |
| Train crossing platform | Time = (L + P) / speed | 180 + 120 over 15 m/s |
| Boat | Down = b + s ; Up = b − s | Stream = (D − U)/2 |
| Catch-up | Gap / relative speed | Lead 4 km, +1 km/h → 4 h |
| Late/early | d/s₁ − d/s₂ = time diff |  |

## Exam Trap ⚠️

> [!warning] Exam Trap ⚠️
> - Pole → length only. Platform/bridge → **length + length**.
> - Average speed for a round trip is **never** the simple mean.
> - Check units: seconds vs minutes, m/s vs km/h, before multiplying.
> - Upstream uses **b − s**; the larger speed is always downstream.
