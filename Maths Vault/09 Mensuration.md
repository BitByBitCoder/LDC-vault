# Mensuration

> [!abstract] 🔴 HIGH · ≈9% of arithmetic questions · Target accuracy **90%+** · Budget **1.5 days**
> Walls vs total surface, longest rod, circle from area, cone — memorise 8 formulas and use π = 22/7.

## Core formulas

| Concept | Formula | Quick example / shortcut |
|---|---|---|
| Rectangle | A = l·b ; P = 2(l+b) |  |
| Triangle / Rhombus | ½·b·h ; ½·d₁·d₂ |  |
| Circle | πr² ; 2πr | Use 22/7 when r is a multiple of 7 |
| Cuboid TSA | 2(lb + bh + hl) | 20×15×10 → 1300 |
| Four walls | 2h(l + b) | **No** floor / ceiling |
| Longest rod / diagonal | √(l² + b² + h²) | 12,6,4 → 14 |
| Square diagonal | side × √2 | d² = 2 × area |
| Cone | CSA = πrl ; TSA = πr(l + r) | l² = r² + h² |

## Exam Trap ⚠️

> [!warning] Exam Trap ⚠️
> - **Four walls** = 2h(l+b). Don't add floor/ceiling unless 'total surface' is asked.
> - CSA vs TSA of a cone: TSA adds the circular base (πr²).
> - Convert paise → rupees (50 paise = ₹0.5) **before** multiplying.
> - Area-to-circumference: find **r first** from πr².
