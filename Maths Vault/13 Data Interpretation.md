> [!abstract] 🟡 MEDIUM · ≈2% of arithmetic questions · Target accuracy **85%+** · Budget **0.5 day**

## Core formulas

| Concept | Formula | Quick example / shortcut |
|---|---|---|
| % increase | (Last − First)/First × 100 | Base = first year |
| Average | Sum / count |  |
| Pie chart value | Angle/360 × total | 54° of ₹500 → ₹75 |
| Times | Total / part | 100% / 5% = 20 |
