# Master Formula Sheet

One page. Read it cold every morning, then close it and write 5 formulas from memory.

## 🔴 HIGH — [[01 Profit Loss and Discount]]

| Concept | Formula |
|---|---|
| Profit % | (SP − CP) / CP × 100 |
| Discount % | (MP − SP) / MP × 100 |
| SP from CP | CP × (100 ± P%) / 100 |
| Successive discounts a, b | a + b − ab/100 |
| Same SP, one +x% one −x% | Loss = x²/100 % |
| False weight | Gain % = error / (true weight − error) × 100 |
| Marked above CP by m%, discount d% | Profit % = (100+m)(100−d)/100 − 100 |

## 🔴 HIGH — [[02 Percentages]]

| Concept | Formula |
|---|---|
| % change | (New − Old)/Old × 100 |
| A is x% more than B → B is less than A by | x/(100+x) × 100 % |
| A is x% less than B → B is more than A by | x/(100−x) × 100 % |
| Successive changes a, b | a + b + ab/100 |
| Price up r% → cut consumption by | r/(100+r) × 100 % |
| Population growth | P(1 + r/100)ⁿ |
| Fail/pass (sets) | Pass = 100 − (A + B − Both) |

## 🔴 HIGH — [[03 Averages]]

| Concept | Formula |
|---|---|
| Average | Sum / n |
| Replace one item | New − Old = n × Δavg |
| Exclude one item | Excluded = old total − (n−1) × new avg |
| Avg of 1 … n | (n + 1)/2 |
| n consecutive numbers | Largest = avg + (n−1)/2 |
| Mode / Median / Mean | Mode = 3 Median − 2 Mean |
| Avg speed, equal distance | 2ab/(a+b) |

## 🔴 HIGH — [[08 Number System HCF LCM and Squares]]
