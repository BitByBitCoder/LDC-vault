# Averages

> [!abstract] 🔴 HIGH · ≈9% of arithmetic questions · Target accuracy **90%+** · Budget **1 day**
> Replacement / excluded-item / consecutive-number questions repeat in nearly every paper. Think in **totals**, never in averages.

## Core formulas

| Concept | Formula | Quick example / shortcut |
|---|---|---|
| Average | Sum / n | Work with Sum = avg × n |
| Replace one item | New − Old = n × Δavg | 8 persons, +2 kg → +16 kg |
| Exclude one item | Excluded = old total − (n−1) × new avg |  |
| Avg of 1 … n | (n + 1)/2 | 1…51 → 26 |
| n consecutive numbers | Largest = avg + (n−1)/2 | avg 20, n=7 → 23 |
| Mode / Median / Mean | Mode = 3 Median − 2 Mean | Median 10, Mode 8 → Mean 11 |
| Avg speed, equal distance | 2ab/(a+b) | 40 & 60 → 48 |

## Visual

```text
  old avg 45  × 20 students = 900 total
  −40 (leaves)  +  2 new (x)   →  21 students × 46 = 966
  900 − 40 + x = 966   →   x = 106   →   avg of 2 = 53
```

## Exam Trap ⚠️

> [!warning] Exam Trap ⚠️
> - Average of speeds over **equal distances** is harmonic (48), not arithmetic (50).
> - Replacement: the change in **total** = n × change in average — not the change in average itself.
> - 'At most how many positive' with avg 0 → n − 1.
> - Check for **'None of the above'** — one question above has no listed numeric answer.
