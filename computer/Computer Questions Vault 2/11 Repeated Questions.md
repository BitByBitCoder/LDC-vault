# 🔁 Repeated Questions (high yield)

These appeared more than once in your set. Learn these first.

### Q96 · Q382 · Q495 🔁 · 🟢 Easy
Status register is also called:  
a) Accumulator  
b) Stack  
c) Counter  
d) Flags

> [!success]- Answer
> **d) Flags**
> Holds condition flags (zero, carry, sign, overflow). Also called Flag register / PSW.

### Q115 · Q410 · Q519 🔁 · 🟢 Easy
Command to see the sub-directory structure of a drive:  
a) Tree  
b) List  
c) Subdir  
d) Subtree

> [!success]- Answer
> **a) Tree**
> TREE. Draws the folder tree. (TREE /F also shows files.)

### Q376 · Q486 🔁 · 🟢 Easy
In magnetic disks, data is organised on the platter in concentric rings called:  
a) Sector  
b) Track  
c) Head  
d) Block

> [!success]- Answer
> **b) Track**
> Rings = tracks. Tracks are cut into sectors (pie slices).

### Q95 · Q381 🔁 · 🟢 Easy
The address bus flows:  
a) Bidirection  
b) Unidirection  
c) Multidirection  
d) Circular

> [!success]- Answer
> **b) Unidirection**
> Address bus is ONE-WAY: CPU to memory/I/O (CPU says where). Data bus is two-way. Hook: Address = Away.

### Q164 · Q391 🔁 · 🟢 Easy
Register containing the address of the next instruction:  
a) Instruction register  
b) Program counter  
c) Accumulator  
d) Container

> [!success]- Answer
> **b) Program counter**
> PC = address of NEXT instruction. IR = the instruction being executed now.

### Q86 · Q400 🔁 · 🟢 Easy
In an analog computer:  
a) Input is first converted to digital form  
b) Input is never converted to digital form  
c) Output is displayed in digital form  
d) None

> [!success]- Answer
> **b) Input is never converted to digital form**
> Analog computers work on continuous physical quantities (voltage, pressure) directly, no digital conversion.

### Q123 · Q413 🔁 · 🟡 Medium
Fragmentation of the file system:  
a) can always be prevented  
b) can be temporarily removed by compaction  
c) is a characteristic of all file systems  
d) None

> [!success]- Answer
> **b) can be temporarily removed by compaction**
> Defragmentation/compaction removes it temporarily; it comes back with use.

### Q618 · Q665 🔁 · 🟢 Easy
Feature automating sending bulk mail / combining names and addresses with a standard document:  
a) mail merge  
b) document formatting  
c) database management  
d) format letters

> [!success]- Answer
> **a) mail merge**
> Mail merge = one letter + data list = many personalised letters.

### Q698 · Q833 🔁 · 🟢 Easy
Device that decides the path of data packets / redirects IP packets to destination:  
a) switch  
b) router  
c) hub  
d) server

> [!success]- Answer
> **b) router**
> Router = chooses path between networks. Switch = connects devices inside a LAN.

### Q374 · Q449 🔁 · 🟡 Medium
Valid statement about a computer program:  
a) HLL must be converted to machine language  
b) HLL programs are faster  
c) Errors harder to find in HLL  
d) All

> [!success]- Answer
> **a) HLL must be converted to machine language**
> High-level language needs a compiler/interpreter. HLL is slower than machine code and easier to debug.
