# MS Word & Document Formatting

#computer #word

**17 questions** · 🟢 11 · 🟡 5 · 🔴 1

## Concept core

- **Mail merge** needs: main document + data source + merge fields (one letter + list = many personalised letters).
- **Word wrap** = automatic next line. **Sizing handles** resize graphics. **Thesaurus** = synonyms/antonyms.
- **Format Painter** copies formatting. **Bookmark** marks a place. **Find and Replace** = Ctrl+H.
- **Orphan** = FIRST line of a paragraph alone at the BOTTOM of a page. **Widow** = LAST line alone at the TOP of the next page.
- Subscript below (H2O), superscript above (x2). Justified = both margins even.
- Autofit a column: double-click its **right** border.
