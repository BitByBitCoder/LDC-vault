Q83: Samples/bit-depth in a DVD-audio digital sound system: (a) 16-bit / b) 18-bit / c) 20-bit / d) 24-bit)::d) 24-bit. DVD-Audio supports 16, 20 and 24-bit. 24-bit is the maximum (CD audio is only 16-bit).

Q92: Memory location addresses are limited to the range: (a) 00000 to 9FFFF(16) / b) 00001 to 9FFFF(16) / c) 00010 to 9FFFF(16) / d) 10000 to 9FFFF(16))::a) 00000 to 9FFFF(16). Addresses start at 00000 (never 00001). 00000-9FFFF hex = 640 KB, the DOS-era conventional memory.

Q102: The idea of cache memory is based: (a) on locality of reference / b) on the 90-10 rule / c) on the fact that references tend to cluster / d) all of the above)::d) all of the above. All three say the same thing: programs reuse nearby and recent data. If two or more options are true, pick 'all of the above'.

Q104: Generally Dynamic RAM is used as main memory because it: (a) consumes less power / b) has higher speed / c) has lower cell density / d) needs refreshing circuitry)::a) consumes less power. DRAM = 1 transistor + 1 capacitor per bit: dense, cheap, low power. Refreshing (d) is a drawback, 'lower density' (c) is false, and SRAM is faster (b). Keys differ on this one; (a) is the commonly accepted answer.

Q105: Main memory is 8K bytes, cache is 2K words, associative mapping. Each word of cache shall be: (a) 11 bits / b) 21 bits / c) 16 bits / d) 20 bits)::b) 21 bits. See Math Corner. Address = 13 bits (8K = 2^13), data = 8 bits (byte). Associative mapping stores full address + data in each cache word: 13 + 8 = 21.

Q107: Maximum addressing capacity of a microprocessor with 16-bit data bus and 32-bit address bus: (a) 64 K / b) 4 GB / c) both a & b / d) None)::b) 4 GB. Capacity depends on the ADDRESS bus only: 2^32 = 4 GB. The 16-bit data bus is a distraction (64K would be 16 address bits).

Q165: Which memory has equal time to access any location: (a) RAM / b) ROM / c) PROM / d) EPROM)::a) RAM. RAM = Random Access Memory: any location, same time.

Q167: 1Kb (1024 bit) memory organised as 1Kx1: number of address lines needed: (a) 6 / b) 10 / c) 14 / d) 18)::b) 10. 1K = 1024 = 2^10 locations, so 10 address lines. (x1 means 1 bit per location.)

Q168: Commonly used Pen Drive nowadays uses: (a) OR flash / b) NOR flash / c) NAND flash / d) AND flash)::c) NAND flash. NAND flash = pen drives, SSDs, memory cards (cheap, dense, block access). NOR flash = firmware/code storage.

Q169: Track organisation in an optical disk: (a) Straight line / b) Parallel lines / c) Concentric circles / d) Spiral)::d) Spiral. CD/DVD has ONE spiral track. Magnetic disks (HDD) use concentric circles.

Q232: Mainly used for checking objective-type answer papers: (a) MICR / b) OMR / c) OCR / d) All)::b) OMR. OMR = Optical MARK Recognition (bubbles). OCR = characters, MICR = magnetic ink (bank cheques).

Q358: Main memory of a computer is: (a) Internal / b) External / c) Both / d) Auxiliary)::a) Internal. Main memory (RAM) is internal/primary. Auxiliary = secondary storage (HDD etc.).

Q376 · Q486: In magnetic disks, data is organised on the platter in concentric rings called: (a) Sector / b) Track / c) Head / d) Block)::b) Track. Rings = tracks. Tracks are cut into sectors (pie slices).

Q377: Performance of cache memory is measured by: (a) miss ratio / b) hit ratio / c) latency ratio / d) read ratio)::b) hit ratio. Hit ratio = (hits / total accesses). Higher = better cache.

Q387: Printer using dry ink powder: (a) Daisy wheel / b) Line printer / c) Laser printer / d) Thermal printer)::c) Laser printer. Laser printers use toner (dry powder). Inkjet = liquid ink.

Q405: Medium to convert text into spoken sentences: (a) Speech Sensors / b) Compact convertors / c) Speech Synthesizers / d) Voice systems)::c) Speech Synthesizers. Text-to-speech = speech synthesizer.

Q494: Optical storage can be defined as: (a) laser used for retrieval / b) optical cable used / c) electromagnetic / d) None)::a) laser used for retrieval. CD/DVD/Blu-ray: data read with a laser.

Q498: Memory that must be refreshed many times per second: (a) EPROM / b) ROM / c) Static RAM / d) Dynamic RAM)::d) Dynamic RAM. DRAM's capacitors leak, so they need refresh. Static RAM does not.

Q161: Fixed number of memory cells processed as a group: (a) Group / b) Memory Set / c) Bump / d) Word)::d) Word. Word = unit the CPU handles at once (word length: 8/16/32/64 bits).

Q95 · Q381: The address bus flows: (a) Bidirection / b) Unidirection / c) Multidirection / d) Circular)::b) Unidirection. Address bus is ONE-WAY: CPU to memory/I/O (CPU says where). Data bus is two-way. Hook: Address = Away.

Q96 · Q382 · Q495: Status register is also called: (a) Accumulator / b) Stack / c) Counter / d) Flags)::d) Flags. Holds condition flags (zero, carry, sign, overflow). Also called Flag register / PSW.

Q106: Communication between microcomputer components takes place via the address and: (a) I/O bus / b) Data bus / c) Address bus / d) Control lines)::b) Data bus. Standard buses = address + data + control. 'Address' is already given and (c) repeats it, so the missing partner is Data bus.

Q164 · Q391: Register containing the address of the next instruction: (a) Instruction register / b) Program counter / c) Accumulator / d) Container)::b) Program counter. PC = address of NEXT instruction. IR = the instruction being executed now.

Q483: Output of ALU operations is stored in: (a) Memory Devices / b) Registers / c) Flags / d) Output Unit)::b) Registers. ALU results go to a register (usually the accumulator). Flags only record status.

Q484: Data is distributed through the system in the order: (a) Output-Input / b) Memory-Processing / c) Input, Processing, Memory, Storage, Output / d) Both a & b)::c) Input, Processing, Memory, Storage, Output. The IPO cycle with storage: Input, Processing, Memory, Storage, Output.

Q487: Common bus specification with the fastest data transfer rate: (a) VL bus / b) ISA / c) PCI / d) All of these)::c) PCI. PCI is fastest of the three. ISA is the oldest and slowest.

Q488: Bus used to connect the monitor to the CPU: (a) PCI bus / b) SCSI bus / c) Memory bus / d) Rambus)::a) PCI bus. Graphics cards sat on PCI (later AGP/PCIe). SCSI = disks, Rambus = RAM.

Q489: Built-in set of machine code instructions of a computer: (a) instruction set / b) transfer of data / c) logical operations / d) logical set)::a) instruction set. Instruction set = all machine instructions the CPU understands.

Q491: Which category of microprocessor instructions detect status conditions: (a) Transfer / b) Operation / c) Control Instructions / d) All of these)::b) Operation. Arithmetic/logic 'operation' instructions set the status flags. Doubtful question; verify against your key.

Q497: Contains processing unit and a small amount of memory: (a) Microprocessor / b) Microcontroller / c) Nanometer / d) Unicontroller)::b) Microcontroller. Microcontroller = CPU + small RAM/ROM + I/O on one chip. Microprocessor = CPU only.

Q504: A machine language instruction format consists of: (a) Operand / b) Operation code / c) Operation code and operand / d) None)::c) Operation code and operand. Opcode (what to do) + operand (what to do it on).

Q554: Control unit's function in the CPU: (a) transfer data / b) store instructions / c) perform logic functions / d) decode instructions)::d) decode instructions. CU fetches and decodes instructions and directs other parts. ALU does logic.

Q777: Internal memory in a processor consists of: (a) set of registers / b) ALUs / c) microprocessor / d) data bus)::a) set of registers. CPU's internal memory = registers.

Q902: ______ unit sends the processed results to the user: (a) Input / b) Output / c) Memory / d) Control)::b) Output. Output unit.
