# 07 · Optical Discs

Data stored as **pits** (tiny dents) and **lands** (flat areas) on a **spiral track** (centre → outside). A **laser** reads the reflection. Non-volatile.

## Capacity ladder
```
CD 700 MB  ──▶  DVD 4.7 GB  ──▶  Blu-ray 25 GB
 infrared        red laser         blue-violet laser
 780 nm          650 nm            405 nm
 (longer wavelength = bigger pits = less data)
```

| Disc | Single layer | Dual layer | Laser |
|------|-------------|-----------|-------|
| **CD** | **700 MB** (80 min audio). Older: 650 MB | n/a | Infrared (780 nm) |
| **DVD** | **4.7 GB** | **8.5 GB** | Red (650 nm) |
| **Blu-ray (BD)** | **25 GB** | **50 GB** | Blue-violet (405 nm) |

- All standard discs are **12 cm**. Mini discs are **8 cm**.
- DVD full form: **Digital Versatile Disc** (earlier "Digital Video Disc").
- **Blu-ray beat HD DVD** in the format war (2008).

## Variants
| Suffix | Meaning |
|--------|---------|
| **-ROM** | Read Only. Factory pressed |
| **-R** | Recordable, write **once** |
| **-RW / -RE** | Re-writable / Re-recordable, many times |

Examples: CD-ROM, CD-R, CD-RW, DVD-ROM, DVD-R, DVD-RW, BD-R, BD-RE.

## Drive speed (1x)
- CD 1x = 150 KB/s · DVD 1x ≈ 1.38 MB/s · Blu-ray 1x = 4.5 MB/s (36 Mbps).
