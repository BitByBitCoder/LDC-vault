# Mnemonics & Memory Hooks

| Fact | Hook |
|---|---|
| Address bus one-way | **A**ddress = **A**way (CPU sends out) |
| PC vs IR | **P**C = **P**ext (next) · **I**R = **I**n progress |
| EPROM vs EEPROM | **E**PROM = UV **E**rase · EE = **E**lectric **E**rase |
| Orphan vs widow | **O**rphan = **O**pening line stranded at bottom; **W**idow = the **W**rap-up line at top |
| Router vs switch | Router = **R**oad between cities; Switch = **S**ame building |
| Simplex/half/full | TV / walkie-talkie / phone |
| OMR vs OCR | **M**arks (bubbles) vs **C**haracters |
| Disk shapes | **HDD = circles (tracks)**, **CD = spiral** (a single groove like a record) |
| Phishing / Pharming / Phreaking | **Ph**ish = **ph**ake email · **Ph**arm = **ph**ake farm (site) · **Ph**reak = **ph**one |
| Safe Mode / BIOS | **F8** = **F**ail-safe (8) · **F2** = setup (2) |
| Generations | 1 Tube · 2 Transistor · 3 IC · 4 Micro · 5 AI |
| 2G | **2G** = **2** things: voice + SMS |
| Bluetooth | blue-tooth: **hopping** frequency |
| Requirement vs design | Requirement = **W**hat · Design = **H**ow |
