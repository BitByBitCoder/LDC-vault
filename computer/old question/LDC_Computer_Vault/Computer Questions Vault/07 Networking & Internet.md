# Networking & Internet

#computer #net

**36 questions** · 🟢 20 · 🟡 14 · 🔴 2

## Concept core

| Term | Fact |
|---|---|
| LAN / MAN / WAN | building / city / country and beyond |
| VPN | private network over public network |
| Router | picks path **between** networks. Switch connects devices **inside** a LAN |
| NIC | card giving physical network connection |
| Modem | MOdulator + DEModulator (digital to analog on phone line) |
| Simplex / Half / Full duplex | one way (TV) / one at a time (walkie-talkie) / both at once (phone) |
| Internet switching | **packet switching** |
| HTTP | **stateless** protocol |
| Static IP | does not change; Dynamic IP changes |
| Bluetooth | frequency hopping spread spectrum |
| Fibre | light signals, no electrical interference |
| UTP | unshielded, noise prone |
| VoIP | calls over Internet |
| P2P | peer to peer |
| M2M | machine to machine (IoT) |

**Standards bodies:** W3C = web standards, IETF = internet protocols, InterNIC = domain names.
