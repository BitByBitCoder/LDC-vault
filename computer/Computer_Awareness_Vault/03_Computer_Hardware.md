# 03. Computer Hardware

### Hardware Overview
Refers to physical, touchable components of a computer system used for processing, inputting, storing, and outputting data.

### Primary Input Devices
* **Keyboard**:
  * Interacts with a keyboard controller and buffer.
  * Layouts include **QWERTY**, **DVORAK**, and **AZERTY**.
  * Contains Alphanumeric keys, Function keys, Numeric keypad, and Cursor control keys.
* **Mouse**:
  * Invented by **Douglas Engelbart** in 1963 at Stanford.
  * Variants: Wireless, Mechanical, Optical.
  * Actions: Click (Left), Double Click, Right Click, Drag and Drop.
* **Trackball**: Alternative to mouse with a ball on top; commonly used on laptops, CAD/CAM workstations, and radar consoles.
* **Joystick**: Moves $360^\circ$ in all directions; pointer keeps moving in chosen direction until stopped; used in flight simulators and CAD/CAM.
* **Light Pen**: Handheld electro-optical pen containing a photocell in a tube; used for menu selections and PDA drawing.
* **Touch Screen**: Employs infrared beams across the screen surface; common in ATMs, hospitals, and reservation systems.
* **Barcode Reader**: Emits light beams to read machine-readable Universal Product Code (UPC) dark/light stripes.
* **Optical Mark Reader (OMR)**: Detects the presence of intended marked responses.
