# 10. Microsoft Office Suite

### 1. MS Excel (Spreadsheet Software)
* **Chart Types**:
  * *Area Chart*: Emphasizes magnitude of change over time.
  * *Column Chart*: Illustrates comparisons over time.
  * *Bar Chart*: Vertical categories with horizontal values.
  * *Line Chart*: Depicts continuous data trends.
  * *Pie Chart*: Displays proportions of a single data series relative to the whole.
  * *XY (Scatter) Chart*: Plots pairs of numeric values.
* **Chart Elements**: Chart Area, Plot Area, Chart Title, Axis Title, Data Series, Gridlines, Legends, Data Label, Data Table.
* **Excel Essentials**:
  * `$` sign locks cell reference locations.
  * *Embedded Chart*: Chart placed directly inside an existing worksheet.
* **Key Shortcuts**:
  * `F2`: Edit active cell.
  * `F11`: Create chart.
  * `Ctrl + ;`: Insert current date.
  * `Ctrl + Shift + ;`: Insert current time.
  * `Alt + =`: AutoSum formula.

### 2. MS PowerPoint (Presentation Software)
* Default file format extension: `.ppt` or `.pptx`.
* **PowerPoint Views**:
  1. *Normal View*: Main editing and design view.
  2. *Slide Sorter View*: Thumbnail representation; optimal for reordering slides and applying global transitions.
  3. *Notes Page View*: Edits speaker notes below each slide.
  4. *Slide Show View*: Full-screen presentation mode.
  5. *Master View*: Includes Slide, Handout, and Notes Masters.
* **Key Details**: Maximum zoom limit is **400%**.
* **Key Shortcuts**:
  * `F5`: Start Slide Show.
  * `Ctrl + M`: Insert new slide.
  * `S`: Pause/Restart slide show.
  * `Esc`: End slide show.

### 3. MS Access (RDBMS)
* Default file format extension: `.accdb`.
* **Core Components**:
  * *Tables*: Store underlying structural data.
  * *Queries*: Retrieve specific data (Types: Select, Parameter, Cross-tab, Action, SQL).
  * *Forms*: User-friendly interface for record entry/editing.
  * *Reports*: Formatted outputs designed for printing.
* **Data Types & Sizes**:
  * *Text*: $0 - 255$ characters (Default size 50).
  * *Memo*: $0 - 65,535$ characters.
  * *Number*: 1, 2, 4, or 8 bytes.
  * *Date/Time* & *Currency*: 8 bytes each.
  * *Yes/No*: 1 bit.
  * *OLE Object*: Up to 1 GB.

### 4. MS Outlook
* Acts as an E-mail client and Personal Information Manager (PIM) capable of managing calendars, task lists, and contacts.
