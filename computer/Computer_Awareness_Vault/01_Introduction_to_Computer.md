# 01. Introduction to Computer

Back to [[00_Index]]

### Definition & Overview
* The word **computer** is derived from the Latin language.
* It is an electronic device that manipulates data/information according to a set of instructions, capable of storing, retrieving, and processing data.

### Basic Functions
1. **Input**: Data and instructions entered into the CPU.
2. **Processing**: Sequence of actions taken on data to convert it into meaningful information.
3. **Output**: Processed results made available to the user.
4. **Storage**: Permanent storage of data and programs.

### Key Features
* **Speed**: Processes millions of instructions per second.
* **Accuracy**: High degree of accuracy based on input instructions.
* **Storage Capacity**: Stores huge amounts of data depending on disk capacity.
* **Versatility**: Performs multiple different tasks simultaneously.
* **Automation**: Executes tasks automatically once instructions are provided.
* **Diligence**: Free from tiredness, monotony, or lack of concentration.
* **Secrecy**: Password protection reduces information leakage.
* **Reliability**: Consistently accurate; errors occur only if input is faulty.
* **Plug and Play**: Automatically configures new hardware and software.

### Key Terminology
* **Hardware**: Physical components of a computer system (e.g., keyboard, display).
* **Software**: Set of programs and procedures telling hardware what to do.
* **Data**: Unprocessed raw facts and figures.
* **Information**: Processed, organized, and structured data.
* **Instruction**: Command given to the computer in computer language.
* **Program**: Set of instructions given to perform a task.

### History of Computers
| Invention | Inventor / Year | Characteristics & Applications |
| :--- | :--- | :--- |
| **Abacus** | China (1602) | First mechanical calculating device; uses horizontal rods; addition, subtraction, square roots. |
| **Napier’s Bones** | John Napier, Scotland (1617) | 3D structure holding numbers 0–9; technology called *Rabdologia*; multiplication. |
| **Pascaline** | Blaise Pascal, France (1642) | First mechanical adding machine; rectangular box with 8 discs; based on liquid pressure. |
| **Jacquard’s Loom** | Joseph Marie Jacquard, France (1801) | Used punched cards for sequence of operations; simplified textile weaving. |
| **Analytical Engine** | Charles Babbage, London (1837) | First general-purpose decimal computer; stored programs in barrels/pegs. |
