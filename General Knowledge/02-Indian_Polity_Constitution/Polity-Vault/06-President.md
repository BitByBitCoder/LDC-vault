## Types of Veto Table

| Veto Type       | meaning                                                                         |     |     |
| --------------- | ------------------------------------------------------------------------------- | --- | --- |
| Absolute Veto   | Withholding assent to a bill passed by legislature                              |     |     |
| Qualified Veto  | Sending bill back, overridden by higher majority (not with Indian President)    |     |     |
| Suspensive Veto | Sending bill back, can be overridden by ordinary majority                       |     |     |
| Pocket Veto     | Taking no action on a bill (used 1986, postal bill, President Giani Zail Singh) |     |     |

## Exam Trap ⚠️
- Zakir Hussain died in office (1969) → triggered V.V. Giri (VP) acting, then he resigned to contest election → CJI Hidayatullah acted → then Giri elected in own right. This 1969 sequence is a favourite MCQ chain.
- This source list is dated — verify current/recent Presidents (Droupadi Murmu onwards) separately as this book predates her tenure.
- Absolute/Suspensive/Pocket veto = President HAS these; Qualified veto = NOT available to Indian President (that's a feature of some other countries).
