# Important Constitutional Cases

| Case                                              | Year | Holding |      |     |     |                                                                                                                                                                        |     |                                                                                                                                                |     |     |
| ------------------------------------------------- | ---- | ------- | ---- | --- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- | ---------------------------------------------------------------------------------------------------------------------------------------------- | --- | --- |

| Keshavananda Bharati Case                         |      |         | 1973 |     |     |                                                                                                                                                                        |     | Preamble IS part of Constitution; Parliament CAN amend FRs (overruling Golaknath) BUT cannot destroy the "basic structure" of the Constitution |     |     |
| Minerva Mills Case                                |      |         | 1980 |     |     |                                                                                                                                                                        |     | Struck down the 42nd Amendment's provisions giving DPSP unlimited precedence over Fundamental Rights                                           |     |     |

| Justice K.S. Puttaswamy (Retd.) vs Union of India |      |         | —    |     |     | Right to Privacy is a protected Fundamental Right                                                                                                                      |     |                                                                                                                                                |     |     |

## Which Case Established What — Quick Recall

| Question | Answer |
|---|---|
| Which case first said Parliament CANNOT amend Fundamental Rights? | ||Golaknath (1967)|| |
| Which amendment tried to counter Golaknath, asserting Parliament's right to amend any part? | ||24th Amendment, 1971|| |
| Which case overruled Golaknath and introduced the "basic structure" doctrine? | ||Keshavananda Bharati (1973)|| |
| Which case struck down the 42nd Amendment's DPSP-over-FR clause? | ||Minerva Mills (1980)|| |
| Which case is the origin of "procedure established by law" being read as fair/just/reasonable (like US "due process")? | ||Maneka Gandhi vs Union of India|| |
| Which case declared Right to Privacy a Fundamental Right? | ||Justice K.S. Puttaswamy (Retd.) vs Union of India|| |
| Which case set the 50% reservation ceiling? | ||Indra Sawhney (Mandal Commission Case)|| |

## Exam Trap ⚠️
- Sequence to memorise: Golaknath (1967, NO amend FR) → 24th Amendment (1971, Parliament asserts power) → Keshavananda Bharati (1973, YES amend but basic structure protected) → 42nd Amendment (1976, DPSP > FR) → Minerva Mills (1980, struck down DPSP > FR).
- Berubari (Preamble NOT part) vs Keshavananda Bharati (Preamble IS part) — always specify which case when this is asked.
