# 11 Assent & Types of Veto

| Question                                               | Answer                                                        |
| ------------------------------------------------------ | ------------------------------------------------------------- |
| Veto power of the Indian President is of which nature? | \|\|Negative\|\|                                              |
| Absolute veto?                                         | \|\|Withhold assent\|\|                                       |
| Suspensive veto?                                       | \|\|Sends back for reconsideration\|\|                        |
| Pocket veto?                                           | \|\|No action immediately (indefinitely)\|\|                  |
| Example of Pocket Veto?                                | \|\|Giani Zail Singh - India Post Office (Amendment) Bill\|\| |
| Qualified veto?                                        | \|\|Not available to Indian President\|\|                     |
| Veto power on Constitution Amendment Bill?             | \|\|No veto power to President\|\|                            |
| Which Amendment took away the veto?                    | \|\|24th Constitutional Amendment Act, 1971\|\|               |

| Veto Type | Meaning | Available to Indian President? |
|---|---|---|
| Absolute | Withhold assent | Yes |
| Suspensive | Send back for reconsideration | Yes |
| Pocket | No action immediately | Yes (Giani Zail Singh - India Post Office (Amendment) Bill) |
| Qualified | - | No |

> [!warning] Exam Trap ⚠️
> - **Qualified veto** - NOT available to Indian President.
> - **Pocket veto** example: Giani Zail Singh - India Post Office (Amendment) Bill.
> - **Constitution Amendment Bill**: no veto -> **24th Amendment, 1971**.
