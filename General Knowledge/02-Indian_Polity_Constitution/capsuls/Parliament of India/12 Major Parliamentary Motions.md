# 12 Major Parliamentary Motions

**Parliamentary Motions** chu MP-ten mipui tana thil pawimawh sawiho tur emaw, sorkar chetdan enfiah tur emawa House-a rawtna an thlen thin hi a ni.
## 1. Original Motion

| Question                    | Answer                                                         |
| --------------------------- | -------------------------------------------------------------- |
| What is an Original Motion? | \|\|Completely independent (not dependent on anyone)\|\|       |
| Examples?                   | \|\|Adjournment Motion, Motion of Thanks (as per textbook)\|\| |

## 2. No-Confidence Motion

| Question                              | Answer                                                         |
| ------------------------------------- | -------------------------------------------------------------- |
| In which House is it moved?           | \|\|Only in Lok Sabha\|\|                                      |
| Minimum proposers?                    | \|\|50 members\|\|                                             |
| Need to give reasons?                 | \|\|No\|\|                                                     |
| If passed?                            | \|\|Government resigns\|\|                                     |
| First No-Confidence Motion?           | \|\|1963 by J.B. Kripalani against J.L. Nehru (not passed)\|\| |
| Total no-confidence motions till now? | \|\|27 (15 against Indira Gandhi)\|\|                          |

## 3. Confidence Motion

| Question      | Answer                                          |
| ------------- | ----------------------------------------------- |
| Who moves it? | \|\|Ruling party, on direction of President\|\| |
| Purpose?      | \|\|To prove majority in Lok Sabha\|\|          |

## 4. Censure Motion

| Question                       | Answer                                         |
| ------------------------------ | ---------------------------------------------- |
| Permission of House required?  | \|\|No\|\|                                     |
| Need to tell reason?           | \|\|No (no need to tell reason for motion)\|\| |
| Against whom?                  | \|\|One minister or Council of Ministers\|\|   |
| Is government bound to resign? | \|\|Not bound to resign, but humiliating\|\|   |

## 5. Adjournment Motion (Work Stoppage Motion)

| Question | Answer |
|---|---|
| Another name? | \|\|Work Stoppage Motion\|\| |
| Purpose? | \|\|To draw attention to an issue of public importance\|\| |
| Support needed? | \|\|At least 50 members\|\| |
| Does it mean resignation of government? | \|\|No - a question on its functioning\|\| |

## Comparison

| Motion | Where | Members needed | Reasons | Result |
|---|---|---|---|---|
| Original | - | - | - | Independent motion |
| No-Confidence | LS only | 50 proposers | Not needed | Govt resigns if passed |
| Confidence | LS | - | - | Ruling party proves majority (President's direction) |
| Censure | - | - | Not needed | Govt not bound to resign, humiliating |
| Adjournment | - | 50 members | - | Question on functioning, not resignation |

> [!warning] Exam Trap ⚠️
> - **No-Confidence**: if passed -> **government resigns**. **Censure**: passed -> govt **not bound** to resign.
> - **No-Confidence** = Lok Sabha **only**; **50 members**.
> - **Confidence Motion** is moved by the **ruling party**, on direction of **President**, to prove majority.
> - **Adjournment Motion** = 50 members; "work stoppage", about *public importance*.
> - First no-confidence: **1963, Kripalani vs Nehru**; total **27**, **15 against Indira Gandhi**.
