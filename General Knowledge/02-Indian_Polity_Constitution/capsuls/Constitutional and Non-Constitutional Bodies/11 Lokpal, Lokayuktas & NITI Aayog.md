# 11 Lokpal, Lokayuktas & NITI Aayog

## Lokpal & Lokayuktas

| Question                               | Answer                                                 |
| -------------------------------------- | ------------------------------------------------------ |
| Lokpal operates at which level?        | \|\|Central level\|\|                                  |
| Created in?                            | \|\|2013 under the Lokpal and Lokayuktas Act, 2013\|\| |
| Structure?                             | \|\|Chairperson + up to 8 members\|\|                  |
| Reservation among members?             | \|\|At least 50% from SC/ST/OBC/Minority/Women\|\|     |
| Judicial members?                      | \|\|50% from Judicial background\|\|                   |
| Appointed by?                          | \|\|President\|\|                                      |
| Tenure?                                | \|\|5 years or till 70 years of age\|\|                |
| Lokayuktas operate at?                 | \|\|State level (appointed by Governors)\|\|           |
| First Lokayukta office established in? | \|\|Maharashtra (1971)\|\|                             |
| Motto?                                 | \|\|"Empower citizens, Expose corruption"\|\|          |
| 1st Lokpal in world?                   | \|\|1809 in Sweden by the name of Ombudsmen\|\|        |
| 1st Lokpal of India?                   | \|\|Pinaki Chandra Ghose (2019)\|\|                    |
| Current Lokpal (textbook)?             | \|\|Ajay Manikrao Khanwilkar\|\|                       |
| Lokpal's investigation includes?       | \|\|Prime Minister; officers of Group A, B, C, D\|\|   |

## NITI Aayog

| Question | Answer |
|---|---|
| Full form? | \|\|National Institution for Transforming India\|\| |
| Established on? | \|\|1 January 2015 (replaced Planning Commission)\|\| |
| Nature? | \|\|Non-Constitutional; Non-Statutory Body\|\| |
| Chairperson? | \|\|Prime Minister\|\| |
| Vice-Chairperson appointed by? | \|\|PM\|\| |
| 1st Vice-Chairperson? | \|\|Arvind Panagariya\|\| |
| Current Vice-Chairperson (textbook)? | \|\|Suman Bery\|\| |
| Executive Officer? | \|\|B.V.R. Subrahmanyam\|\| |
| Function 1? | \|\|Formulating National Policy and strategy\|\| |
| Function 2? | \|\|Development Agenda\|\| |
| Function 3? | \|\|Monitoring and Evaluating government programs\|\| |

> [!warning] Exam Trap ⚠️
> - **Lokpal**: **Act 2013**, first Lokpal **2019 (P.C. Ghose)**, tenure **5 yrs / 70**; **Lokayukta** = state, first in **Maharashtra 1971**.
> - **World's first Ombudsman**: **Sweden, 1809**.
> - **NITI Aayog** (1 Jan 2015) = **non-constitutional AND non-statutory**; chaired by **PM**; replaced **Planning Commission**.
> - Lokpal's reach includes the **Prime Minister** and **Group A-D** officers.
