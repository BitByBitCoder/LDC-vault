## A simple memory trick

Most abstract nouns follow one of these endings:

- **-ness** → kind → kindness, happy → happiness
    
- **-ity / -ty** → able → ability, honest → honesty
    
- **-ence / -ance** → patient → patience, innocent → innocence
    
- **Special forms** → wise → wisdom, strong → strength, beautiful → beauty
    

If you master these patterns and the irregular "special forms," you'll be well prepared for most competitive exam questions on abstract nouns.
