## How to Use This Vault
1. Byhard the **Toolkit** first — connecting words, word swaps, argument phrases. These apply to every essay regardless of topic.
2. For each topic page: read the **guide** (angle + 3 points + vocabulary) and the **model essay** to see the formula applied.
3. In the exam: don't recall the model essay word-for-word — recall the **structure and vocabulary**, then write your own sentences. Focus on the idea, not memorized lines.
4. Every topic follows the same 5-paragraph formula (Intro → Point 1 → Point 2 → Point 3 → Conclusion). Only content and vocabulary change.

### Exam Trap ⚠️
- Don't reuse the same connecting word twice in one essay
- Don't repeat "important / good / bad / many" — swap using the Toolkit
- A concrete example (a scheme name, statistic, or known case) scores higher than a generic statement
